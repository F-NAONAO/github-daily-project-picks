01 / AI + 数据分析AI + DATA

DuckQuery：把散装表格变成一句话能问的数据台

Chenkeliang/duckdb-query ↗
一句话介绍

本地优先的 SQL 工作台：Excel、CSV、数据库丢进去直接查、跨表关联，AI 帮你写 SQL、修报错、荐图表。

普通人使用场景

月底对账要把导出的 Excel 和业务库对一遍，或者手里一堆 CSV 想快速找出重复、异常和总数。

小白体验步骤

先开浏览器演示版免安装导入 CSV 就能查、能出图；要连数据库和 AI 问数再装 Win/mac 桌面版，AI 功能需自己的模型 Key。

可以提升

练 SQL 的 JOIN、透视表和跨源对账思路，还能看 AI 怎么解释和优化你写得不顺的查询。

学习价值

8/10

推荐理由

桌面版功能全，网页演示零门槛当天可用；注意 AI 是可选增强，得自己配 Key，不配也能正常查数出图。

02 / AI办公自动化AI + WORKFLOW

海豹办公：免费开源的 AI 办公全家桶

fangzhouxiaohai/seal-office ↗
一句话介绍

开源办公套件，文字、表格、演示、PDF 一套齐，内置 AI 助手能写能改能问答，拍照识别还能转表格。

普通人使用场景

不想装盗版 Office 又想要个够用的文档工具，顺便让 AI 帮忙起草周报、润色通知、整理纸质单据。

小白体验步骤

浏览器直接打开网页版就能新建文档体验；桌面版去 GitHub Releases 下 Win exe 或 mac dmg，AI 助手要在设置里配模型服务。

可以提升

练 AI 侧边栏的起草与改写工作流，以及用拍照识别把纸质单据一键变成可编辑表格。

学习价值

7/10

推荐理由

全平台免费、网页版零安装，拍照转表格实用；但宏、透视表等高级功能还不完整，重要文件操作前先备份。

03 / AI知识管理AI + KNOWLEDGE

Happy Friday Lite：装在电脑里的个人知识管家

cheney-plus/happy-friday-lite ↗
一句话介绍

桌面 AI 助手：本地知识库带出处问答、富文本笔记、日程和画图一锅端，还能替你执行整理类任务。

普通人使用场景

资料散在各处，想让 AI 读完你本地的 PDF、Word、EPUB 再回答问题，顺便记笔记、管日程、画流程图。

小白体验步骤

GitHub Releases 下载 Win 安装包或 mac dmg，装好在知识库页导入文档建索引；AI 问答和助手需配置模型 Key。

可以提升

练 RAG 知识库的资料整理习惯：分库、打标签、增量索引，让 AI 的每个答案都有出处可查。

学习价值

8/10

推荐理由

数据全本地、隐私可控，知识库加笔记加日程整合度高；首次导入大文档建索引要等一会，AI 能力需自配 Key。

04 / AI创作与内容AI + CREATION

书童 Pagekin：免费 AI 小说软件，一章一章写完一本书

EthanYoQ/Pagekin ↗
一句话介绍

桌面 AI 写作软件：从设定、大纲、章节蓝图到正文、审稿、修稿全流程，AI 负责起草，你负责拍板。

普通人使用场景

一直想写小说但总卡在开头上，或者已有旧稿想导入续写、拆解喜欢的作品来仿写文风。

小白体验步骤

官网 orz.md 看介绍和实录视频，再到 GitHub Releases 下载 Win exe 或 mac dmg；软件免费不带模型，接自己的 API Key 或本地 Ollama。

可以提升

学会把创作拆成设定、架构、蓝图、正文的流水线，用审稿加修稿的循环一点点磨文笔。

学习价值

9/10

推荐理由

免费开源、作品存本地，拆解仿写和逐段修稿做得很细；要自己准备模型 Key，批量生成时记得控制篇幅。

普通人使用场景

学习价值

7/10

推荐理由

中文项目社区活跃，情绪识别和屏幕感知是亮点；纯娱乐向，需要自己的模型 Key，别指望它干活。
