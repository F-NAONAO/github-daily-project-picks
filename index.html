01 / AI + 数据分析AI + DATA

RTutor：上传 Excel 就能问着分析

gexijin/RTutor ↗
一句话介绍

上传 CSV 或 Excel，用一句话提问，它现场写 R 代码跑出图表，还能导出整份 HTML 分析报告。

普通人使用场景

手里有一张几千行的销售表或问卷表，不会写公式和透视表，只想问「哪个月卖得最好」并马上看到图。

小白体验步骤

打开 rtutor.ai，先点 EDA 看概况，选好刚上传的表，在提问框里写需求；不用注册，报告能直接下载。中文提问可用，但界面是英文。

可以提升

练把业务问题拆成能算的口径，学会检查它生成的 R 代码有没有跑偏

学习价值

8/10

推荐理由

零安装，浏览器里跑完「提问—出图—出报告」。限制：结果可能算错要自己核对；免费仅限非商用；只吃规整的二维表。

02 / AI办公自动化AI + WORKFLOW

Meetily：开会自动记纪要的本地工具

Zackriya-Solutions/meetily ↗
一句话介绍

Windows、macOS 装好就能录会议，本地 Whisper 转文字，再接模型生成摘要，录音和文字都不出本机。

普通人使用场景

每周组会、客户电话一堆，边听边记跟不上，会后还要花半小时回忆到底谁说了什么。

小白体验步骤

到 meetily.ai 或 Releases 下安装包（Windows 用 x64-setup.exe，Mac 用 dmg），装好点录音选麦克风或系统声音，摘要接本机 Ollama 或填模型 Key。

可以提升

练会前准备、会后把纪要拆成待办，以及给不同会议定摘要模板

学习价值

9/10

推荐理由

三万多人用过的会议纪要工具，Windows 也能跑，本地转写不花订阅费。限制：说话人区分、PDF/Word 导出属付费 PRO；CPU 要支持 AVX2。

03 / AI知识管理AI + KNOWLEDGE

ReadAny：能对着书提问的本地阅读器

codedogQBY/ReadAny ↗
一句话介绍

把电子书拖进书架，边读边划重点，AI 只基于这本书回答，还能按意思搜，不靠关键词。

普通人使用场景

囤了一堆 PDF 和 EPUB，读完只记得大概，想回头找「那本讲复利的书里怎么说的」却翻不到。

小白体验步骤

从 Releases 下 Windows 的 exe 或 msi（Mac 用 dmg），导入书后双击打开，设置里填 API Key 或接 Ollama，就能划词提问、语义搜索、导出笔记。

可以提升

练划线标注、把问答结果沉淀成读书笔记，再串成自己的主题

学习价值

8/10

推荐理由

书和笔记都留本机，向量检索也跑在本地，比上传云端踏实。限制：不填模型 Key 只有阅读和普通搜索；扫描版 PDF 得先自己 OCR。

04 / AI创作与内容AI + CREATION

Oh My PPT：本地 AI 做 PPT，能导回 PPTX

arcsin1/oh-my-ppt ↗
一句话介绍

说清主题就自动出大纲、排版和配图，做完能演示、能改，也能导出成 PowerPoint 里可继续编辑的文件。

普通人使用场景

周五要交汇报，模板挑半天、排版老对不齐；或者客户给了旧 PPTX 模板，想在上面快速换内容。

小白体验步骤

到 ohmyppt.cc 或 Releases 下 Windows 的 exe（Mac 用 dmg），装好后在设置里填一个模型 Key（也可接本地 Ollama），回首页填主题就能生成。

可以提升

练把汇报讲清楚：先定结构和重点，再让 AI 排版，最后自己改措辞

学习价值

8/10

推荐理由

桌面端本地跑，自带九十多套风格，最实用的是能把 HTML 稿导成可编辑 PPTX。限制：未签名安装包会被系统拦一下；生图改稿要耗模型额度。

05 / AI生活实验室AI + LIFE

MoChord：吉他手的 AI 练习室

Mocha-Yuan/MoChord ↗
一句话介绍

输入一个调式或级数走向，AI 给两套和弦进行，配指板图、试听、调音器和节拍练习。

普通人使用场景

想写首歌或练段进行，一会儿查和弦网站、一会儿开调音器、一会儿找节拍器，来回切窗口。

小白体验步骤

从 Releases 下 MoChord_x64-setup.exe 装到 Windows（也有安卓包），不填 Key 也能用本地兜底算法，填 DeepSeek Key 后生成的进行更有色彩。

可以提升

练级数与功能和声、把位怎么选，以及按 BPM 分轮提速的练习方法

学习价值

7/10

推荐理由

把和弦、把位、调音、节拍塞进一个窗口，两百来星的小项目但真能用。限制：偏吉他，键盘用户用不上；调音要开麦克风；云同步得自己配。
