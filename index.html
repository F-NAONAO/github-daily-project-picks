01 / AI + 数据分析AI + DATA

openhare：会帮你写 SQL 的桌面数据库客户端

sjjian/openhare ↗
一句话介绍

一个装着 AI 的数据库客户端，你用大白话说想查什么，它把 SQL 写出来，还会先标出危险语句让你确认。

普通人使用场景

手里有 SQLite 或 DuckDB 数据文件，想知道「上个月哪类订单退得最多」，却卡在不会写查询上。

小白体验步骤

官网或 Releases 下 Windows 安装包（macOS 是苹果芯片 dmg），新建 SQLite 连接指向本地 .db 文件，在 AI 框里提问；需自备 OpenAI 兼容接口的 Key。

可以提升

练自然语言转 SQL、看懂查询逻辑、上手最基础的取数与聚合。

学习价值

8/10

推荐理由

原生桌面客户端，装完十几分钟就能连库问数；限制是要先有数据库文件，macOS 只提供苹果芯片包。

02 / AI办公自动化AI + WORKFLOW

AiNiee：文档、字幕、漫画一键翻成中文

NEKOparapa/AiNiee ↗
一句话介绍

把一个 Word、PDF、epub、字幕或整本漫画丢进去，它自动认语言并整篇翻译，译文格式基本不乱。

普通人使用场景

收到英文报告、外语教程字幕、生肉漫画，想快点看懂，又不想一段段复制到翻译网站。

小白体验步骤

Releases 下 AiNiee7.3.0-Windows-Portable.zip 解压即用（macOS 有 dmg），在接口设置里填 DeepSeek 等 Key，再把文件拖进窗口点开始。

可以提升

摸清 AI 翻译的质量与成本边界，学会用术语表和上下文让译文更顺。

学习价值

8/10

推荐理由

老牌工具，文档、字幕、漫画一个入口就够；限制是必须自备付费 API，长文档要算 Token 成本。

03 / AI知识管理AI + KNOWLEDGE

归知 GuiZhi：数据留在本机的 AI 知识库

Couleur-Share/GuiZhi ↗
一句话介绍

把网页、笔记、图片、音视频收进本地知识库，AI 做摘要、打标签、带出处问答，再编成互相链接的 Wiki。

普通人使用场景

刷到好文章、好视频就随手存，过几天想找「上次那篇讲 XX 的」，翻遍收藏夹也翻不出来。

小白体验步骤

下 GuiZhi-Setup-x64.exe（Windows 11 x64）安装，设置里给主文本和快速模型填 Key，按 Alt+Shift+N 粘链接入库。

可以提升

练资料采集、标签体系、带引用的问答，把碎片攒成能复用的知识。

学习价值

8/10

推荐理由

全中文、免注册、数据留本机，能直接收抖音和 B 站链接；限制是只有 Windows 安装包，项目还比较新。

04 / AI创作与内容AI + CREATION

万稿汇 AIMedia：写稿改稿排版一条龙

Anning01/AIMedia ↗
一句话介绍

桌面写作工具：找热点素材、AI 生成正文、去 AI 味、套模板排版，最后把文章推进公众号草稿箱。

普通人使用场景

公众号每周要更新，卡在选题和开头，写完还得在好几个工具之间来回切换排版。

小白体验步骤

下 AIMedia-1.0.7-win-x64-Setup.exe（Mac 有 dmg），AI 配置里选「器灵一键授权」或填自己的 Key，再到创作工坊输入主题生成。

可以提升

练选题判断、把 AI 初稿改成人话、固定一套排版规范。

学习价值

8/10

推荐理由

少见的把写作到发布串成一条线的开源桌面工具，公众号只推草稿更安全；限制是去 AI 味要授权器灵，AI 调用按量付费。

05 / AI生活实验室AI + LIFE

彩读 ColorTxt：能陪你精读小说的本地阅读器

ssnangua/ColorTxt ↗
一句话介绍

本地电子书阅读器，除了多音色朗读，还能让 AI 分析剧情、答人物关系、画思维导图和词云。

普通人使用场景

追长篇网文或啃厚书，人物一多就记混，想边读边问「这人前面到底干过什么」。

小白体验步骤

Releases 下 Windows 安装包或便携版（macOS 有 arm64 与 x64 的 dmg），导入 txt/epub，设置里填 DeepSeek 等 Key 后就能问 AI。

可以提升

练用检索增强的思路提问、整理人物关系图，理解 AI 读长文为什么先要建索引。

学习价值

8/10

推荐理由

阅读器本身免费好用，AI 是加分项不喧宾夺主；限制是 AI 要自备 Key，不配向量模型就退化成全文检索。
