01 / AI + 数据分析AI + DATA

花叔 Excel：让 AI 算的每个数都答得上来

alchaincyf/huashu-excel ↗
一句话介绍

给 AI 助手装一套数据分析标准流程：先体检脏表再动手，交付前拿表里的合计行对账，对不上就不给数字

普通人使用场景

把一份带合并表头、合计行、千分位的销售表丢给 AI，出了结论却被人问「这数你怎么算的」

小白体验步骤

在 Claude Code、Codex、DSH 里跑 npx skills add alchaincyf/huashu-excel；没装助手就直接跑 scripts/profile_table.py 你的表.xlsx

可以提升

表结构体检、脏数据清洗、指标口径对齐、交付前对账复核

学习价值

9/10

推荐理由

免费开源、只依赖 openpyxl，主打「AI 算错不会报错」这个真痛点；但它是个技能不是双击能用的软件，得有个 AI 助手来装

02 / AI办公自动化AI + WORKFLOW

TrendRadar：35 个平台热榜，AI 只留你真要看的

sansan0/TrendRadar ↗
一句话介绍

聚合抖音、知乎、B 站等多平台热榜和 RSS，AI 帮你筛掉噪音、翻译外文、写成简报，再推送到微信或飞书

普通人使用场景

每天刷一小时热搜还是错过重点，想给自己或团队做一份只留关键信息的早报

小白体验步骤

先把仓库 fork 到自己 GitHub，照官网文档填推送地址，用 Actions 定时跑，全程不花钱；有 Docker 也能本机起

可以提升

信息源配置、关键词与 AI 筛选规则设计、自动化推送链路

学习价值

8/10

推荐理由

6.3 万星、两周内还在更新，部署号称 30 秒；纯看热榜不用 AI，AI 分析与简报要自己配模型密钥

03 / AI知识管理AI + KNOWLEDGE

Knowledge Base：装在自己电脑里的知识库

bkywksj/knowledge-base ↗
一句话介绍

Windows/macOS 桌面应用，Markdown 笔记配全文搜索、双向链接和知识图谱，还能接自己的模型做带库问答

普通人使用场景

资料散在微信、PDF、Word 里，想建自己的资料库，又不愿意把内容传到别人服务器

小白体验步骤

Releases 下 Knowledge.Base_3.1.0_x64-setup.exe 装上，选一个本地文件夹当库，导入 md/pdf/docx；AI 问答填 OpenAI 兼容或 Ollama

可以提升

笔记分类体系、双链组织、全文检索、本地模型接入

学习价值

8/10

推荐理由

零云端依赖，可走 WebDAV/S3 同步，笔记还能加密；AGPL 协议，想闭源商用要另外买授权

04 / AI创作与内容AI + CREATION

易拓排版工坊：Markdown 一键变公众号排版

yan9651688/yituo-hub-studio ↗
一句话介绍

把 Markdown 排成能直接粘进公众号编辑器的内联样式 HTML，20 套主题、81 种分级排版、79 组动静态组件

普通人使用场景

稿子写完了，在公众号后台一段段调格式调到崩溃，粘过去样式还掉一半

小白体验步骤

打开 studio.yituohub.com 点开始排版，粘 Markdown、挑主题、点「复制到公众号」再粘贴；AI 写作和润色要自带 API Key

可以提升

Markdown 写作、公众号排版红线、组件化表达与封面导出

学习价值

9/10

推荐理由

纯静态零构建、复制后样式不丢，还带合规校验；主题偏模板化，想更深定制还是得自己改 HTML

05 / AI生活实验室AI + LIFE

Local Lens：不上传云端，也能整理几万张照片

ashesbloom/LocalLens ↗
一句话介绍

AI 相册管家，按人脸、时间、地点把电脑里的照片自动分组，全程离线，一张都不上传

普通人使用场景

手机相册几万张照片，想找出某个人的全部照片或某次旅行的合影，又不想交给云端

小白体验步骤

Releases 下 Windows 的 setup.exe 或 macOS 的 dmg，装好指一个照片文件夹，首次会下载识别模型，之后纯本地跑

可以提升

本地模型的下载与运行、照片元数据整理、数据隐私边界判断

学习价值

8/10

推荐理由

免费开源、Win/mac 都有现成安装包，装完就能用；首次建索引吃 CPU，老电脑要等挺久
