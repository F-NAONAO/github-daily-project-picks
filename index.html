01 / AI + 数据分析AI + DATA

迹忆 TraceMemo：把微信聊天记录变成能搜能问的数据

Wxw-Gu/TraceMemo ↗
一句话介绍

本地解析你的微信聊天记录，能搜索、生成群聊日报，还能用 AI 直接问「上次谁在哪句话里说过什么」。

普通人使用场景

群消息几千条翻不到头、记得聊过但找不到出处、想知道群里谁最活跃谁一直潜水——它都能直接给答案。

小白体验步骤

Releases 下 Windows 或 Mac 安装包装好，选微信数据目录连接；浏览搜索统计不用 AI，要 AI 问答再在设置里填一个模型 Key。

可以提升

练把生活数据当数据库用：关键词检索、发言量统计、用自然语言查历史记录。

学习价值

9/10

推荐理由

装好就能用，搜索统计全程本地不联网，还能自动出群日报；限制是要本机微信 4.x 数据，AI 问答需自配 Key。

02 / AI办公自动化AI + WORKFLOW

OpenWorkBuddy：说一句话，交给你能打开的 PPT 和周报

CatCatUncle/openworkbuddy ↗
一句话介绍

跑在自己电脑上的 AI 办公助理，真能生成 PPT、Word、Excel、网页文件，不是只回一段聊天记录。

普通人使用场景

天天手搓周报、汇报 PPT、会议纪要的人：丢一句需求加一份资料，它在成果区给你能直接打开再改的文件。

小白体验步骤

Releases 下载 Win 安装版或 mac dmg，装好注册账号，设置里填 DeepSeek/Kimi 等任意一家 Key，粘一句话任务就能跑。

可以提升

练用任务描述驱动 AI 干活：讲清对象、页数、要求，再验收它交回的真实文件。

学习价值

9/10

推荐理由

个人非商用免费，模型随便换还能接本机 CLI；它有权限跑命令，重要任务要留意审批卡，商用需购授权。

03 / AI知识管理AI + KNOWLEDGE

ZettelAgent：装在本机的第二大脑，笔记自己长出联系

Poetrynan/ZettleAgent ↗
一句话介绍

本地 Markdown 笔记库加混合检索和 AI 整理：关键词、语义、知识图谱一起上，帮你找到关联的想法。

普通人使用场景

笔记记了一堆从来不再打开的人：让它自动建索引找关联，AI 帮你把零散笔记组织成有结构的知识。

小白体验步骤

Releases 下载 Win exe/msi 或 mac dmg，打开一个本地 Markdown 文件夹当笔记库，建好索引配一个模型 Key 就能问答整理。

可以提升

练卡片盒笔记法：双链、图谱、FSRS 间隔复习，让知识真正复利起来。

学习价值

8/10

推荐理由

数据全在本地、内置中文语义模型可离线检索；首次建索引要等一会儿，开自动整理前建议先看权限设置。

04 / AI创作与内容AI + CREATION

创作有数：一份资料管好公众号小红书等五平台稿件

ehomekevin/personal-ip-workbench-open-source ↗
一句话介绍

本地优先的自媒体工作台：一个选题保留原始资料、核心稿和各平台版本，还带排期与数据复盘。

普通人使用场景

小白体验步骤

可以提升

8/10

推荐理由

05 / AI生活实验室AI + LIFE

TuneFree：免费开源桌面音乐播放器，AI 帮你搜歌

alanbulan/TuneFree ↗
一句话介绍

聚合网易云、QQ、酷我多音源的桌面播放器，带透明桌面歌词、本地推荐，支持自然语言语境搜歌。

普通人使用场景

电脑前写东西想配 BGM：一个软件搜三个平台的歌，开着桌面歌词，说一句「想要专注时的钢琴曲」让它挑。

小白体验步骤

Releases 下 Win 安装向导或 mac 通用 dmg，装好直接搜歌播放；AI 语境搜歌在设置里选填一个 OpenAI 兼容 Key。

可以提升

体验 AI 推荐链路：本地播放行为召回加模型重排，直观感受个性化推荐怎么工作。

学习价值

8/10

推荐理由

MIT 免费无广告、安装即用；音源来自第三方解析，歌曲可用性随平台变动，个别歌可能放不出来。
