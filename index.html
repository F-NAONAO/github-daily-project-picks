01 / AI + 数据分析AI + DATA

Teable｜像表格一样整理和分析数据

teableio/teable ↗
一句话介绍

在网页表格里导入数据，做筛选、分组、汇总和图表；云端版本还提供用自然语言分析数据的 AI 功能。

普通人使用场景

把一份模拟订单表导入，看看哪个品类卖得最好，再画出每月销售变化。

小白体验步骤

打开官网云端版并注册，导入一份不含隐私的 CSV，先做分组和图表；AI 聊天是否可用取决于云端方案。自行部署的免费独立版没有 AI 聊天。

可以提升

练习清理字段、设定统计口径、核对 AI 给出的结论与原始数据。

学习价值

8/10

推荐理由

GitHub 约 2.2 万星，10 月 17 日仍有更新；表格界面适合数据分析入门，但 AI 功能有版本门槛。

02 / AI办公自动化AI + WORKFLOW

aaif-goose/goose ↗
一句话介绍

可安装在电脑上的 AI 助手，能协助研究、写作、整理文件和执行多步任务；支持多种模型和扩展。

可以提升

练习把模糊任务拆成步骤、限定 AI 可操作范围，并检查最终文档。

学习价值

8/10

推荐理由

GitHub 约 5.5 万星，10 月 17 日仍有更新；有桌面界面，首次使用需要模型连接。

03 / AI知识管理AI + KNOWLEDGE

Kallamo｜给自己的资料建一个可提问的知识库

Kallamo/Kallamo ↗
一句话介绍

桌面知识工作台，可导入 PDF、Word 和文本笔记，让 AI 助手根据自己的资料回答问题，还能保存聊天记忆。

普通人使用场景

导入几篇自己写过的公众号草稿，问它哪些话题重复、哪些观点值得继续写。

小白体验步骤

从 Releases 下载 Windows 或 macOS 安装包；先连接自己的模型 API Key，或配置本地 Ollama。新建知识库，导入几份无敏感信息的文档后提问。

可以提升

练习整理素材、提出有范围的问题，并回到原文核对 AI 的回答。

学习价值

7/10

推荐理由

AGPL 开源，约 20 星；提供桌面安装包和本地知识库，最近一次仓库更新为 9 月 15 日，仍属小型项目。

04 / AI创作与内容AI + CREATION

Cutawan｜把长视频剪成带字幕的短片

JeremySNR/cutawan ↗
一句话介绍

桌面视频剪辑工具，可把访谈、播客或录屏变成竖屏短片，支持字幕、画面调整和 AI 挑选片段。

普通人使用场景

把一次 10 分钟的分享录屏，剪成一条适合发布的 1 分钟知识短片。

小白体验步骤

从 Releases 下载 Windows 或 Apple 芯片 macOS 安装包；先试无需模型连接的整片字幕模式。要 AI 自动挑片段，需配置兼容模型 API，或按说明登录 Codex 并安装 Python。

可以提升

练习判断内容重点、改字幕节奏，并比较 AI 选段与自己选段的效果。

学习价值

8/10

推荐理由

MIT 开源，约 34 星，10 月 13 日仍有更新；可先离线体验字幕剪辑，AI 挑片需额外配置。

05 / AI生活实验室AI + LIFE

OpenKara｜把自己收藏的音乐变成家庭 K 歌

thedavidweng/OpenKara ↗
一句话介绍

桌面卡拉 OK 工具，用本机 AI 把已拥有的歌曲分离成人声和伴奏，配合歌词、歌单与轮唱功能。

普通人使用场景

挑一首自己已有的本地歌曲，分离伴奏，和朋友轮流唱。

小白体验步骤

从 Releases 下载 Windows 或 macOS 安装包；首次启动创建歌库并等待 AI 模型下载，再导入自己拥有的本地音频文件。无需模型 API Key，但分离歌曲需要一定时间。

可以提升

亲手体验本地 AI 的音频处理，理解人声、伴奏和歌词如何组成一段可玩的互动体验。

学习价值

8/10

推荐理由

AGPL 开源，约 34 星，10 月 16 日仍有更新；跨平台安装方便，需要本地歌曲和首次下载模型。
