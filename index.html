01 / AI + 数据分析AI + DATA

Metabase：拖拽做数据看板

metabase/metabase ↗
一句话介绍

开源可视化分析工具，可连接表格或数据库，用点选方式筛选、汇总并做图表；自带示例数据可练习。

普通人使用场景

把销售或运营 CSV 变成趋势图和仪表板，先从示例订单数据练习，再套用到自己的 Excel/CSV。

小白体验步骤

先安装 Docker Desktop，按官方 Docker 快速开始复制一条启动命令；打开本机页面，选择内置 Sample Database，点选汇总与图表。

可以提升

表格数据思维、指标定义、筛选汇总与图表表达

学习价值

7.5/10

推荐理由

成熟开源项目，自带可练习数据和无代码查询；首次启动需要 Docker，电脑未安装时会多花一些准备时间。

02 / AI办公自动化AI + WORKFLOW

Feather：随手改写窗口里的文字

yurirxmos/feather ↗
一句话介绍

Windows、macOS、Linux 桌面写作助手，按快捷键读取当前输入框或选中内容，帮你润色邮件、回复和文档，再插回原窗口。

普通人使用场景

在飞书草拟通知、回复邮件或润色公众号段落，让 AI 结合当前窗口内容按指定语气改写。

小白体验步骤

安装 Windows 版；在设置里连接 OpenAI、Claude 或 OpenCode Go 的 API Key，或使用 Feather Plus；按首次启动提示授权，再选中草稿按快捷键描述修改。

可以提升

把工作要求说清楚、检查 AI 改写、建立自己的办公表达模板

学习价值

7/10

推荐理由

不用反复切换窗口，适合从一段真实工作文字开始体验；需要先配置模型，调用时当前窗口内容会发给所选模型服务。

03 / AI知识管理AI + KNOWLEDGE

Keel：把 AI 记忆放在自己的电脑

Keel-Labs/keel ↗
一句话介绍

本地优先的 AI 桌面工作台，把项目记录、任务、日记和知识库保存为本机 Markdown，再让可切换的模型根据这些资料回答。

普通人使用场景

把公众号选题、资料摘要和待写文章收进同一个项目，第二天继续追问，减少跨对话找资料。

小白体验步骤

下载安装 Windows x64 版；首次打开连接 OpenAI、Anthropic、OpenRouter 的 API Key 或本地 Ollama；建一个内容项目，保存几条选题，再试着让助手归纳。

可以提升

个人知识整理、持续积累上下文、检查 AI 回答的资料依据

学习价值

6.5/10

推荐理由

本地 Markdown 记录适合长期积累内容素材；Windows 版仍属 beta、由个人维护，需配置模型，建议先用少量资料试用。

04 / AI创作与内容AI + CREATION

StykAnimate：把点子做成逐帧动画

filippocalippo/StykAnimate-App ↗
一句话介绍

浏览器里的开源逐帧动画工具，可做火柴人动作、加图层与特效并导出 GIF/MP4；项目本身不内置 AI。

普通人使用场景

先让自己的 AI 想一个 10 秒分镜，再亲手把人物动作做成趣味 GIF，用来表达一个公众号观点。

小白体验步骤

打开网页版，从简单火柴人动作开始逐帧调整，在时间轴试节奏，最后导出 GIF；无需安装桌面程序。

可以提升

分镜拆解、节奏感、动手表达与核对 AI 草稿

学习价值

8.5/10

推荐理由

打开网页就能开始创作，短时间能做出可分享的动图；它是 AI 辅助创作的载体，不是 AI 生成器。

05 / AI生活实验室AI + LIFE

Word Atlas（词光）：插画背词星图

designfuchen/word-atlas ↗
一句话介绍

免费开源雅思词汇网页，把插画、英美音与间隔复习做成可探索的词汇星图；应用本身不调用 AI，部分学习内容由生成式 AI 制作且未经逐条人工审校。

普通人使用场景

通勤时背一组词，听发音、看插画、做主动回忆；再让自己的 AI 用这些词生成一段简单英语对话，回到应用复习。

小白体验步骤

打开官方在线版，选今日词卡，先看图猜词、切换英美音、完成回忆题；无需账号，可离线缓存，换设备前先导出进度。

可以提升

英语词汇积累、主动回忆、间隔复习，以及检查 AI 生成练习内容

学习价值

8.5/10

推荐理由

无需注册、浏览器就能体验；GitHub 仓库近期关注度上升。应用本身不提供 AI 对话，且官方提醒部分生成内容未逐条人工审校。
