01 / AI + 数据分析AI + DATA

Dataloupe｜点开 CSV 就能探索数据

aurelio-nakamura/dataloupe ↗
一句话介绍

把 CSV、Excel 等文件变成独立 HTML 数据探索页，可筛选、排序、看统计与图表；还提供供 AI 助手查询本地数据的接口。

普通人使用场景

拿公开样例练习观察数据分布、缺失值与变量关系；暂不上传含个人或公司信息的表格。

小白体验步骤

先打开在线演示的 penguins 样例，试筛选、排序和查看统计图。想看自己的文件再装 Node.js 18+，本机运行 npx dataloupe 文件.csv --open。

可以提升

从数据分布和图表里发现问题；以后接入 MCP 时，还能练习让 AI 查数据并核对结果。

学习价值

8.6/10

推荐理由

README 说明页面可离线使用、数据留在浏览器，并提供在线样例；基础体验无需 API Key。

02 / AI办公自动化AI + WORKFLOW

Open Cowork｜让 AI 试做办公任务

OpenCoworkAI/open-cowork ↗
一句话介绍

Windows/macOS 桌面 AI 助手，可在指定文件夹里处理文档、表格、PPT 和网页任务，并展示执行过程。

普通人使用场景

在空的练习文件夹里，让它根据公开材料整理一页简报，观察它如何拆解任务并生成文件。

小白体验步骤

下载 Windows/macOS 客户端→选一个新建的空文件夹→配置模型服务和 API Key→用公开资料试做。先逐步确认结果，不连接私人文件或群聊。

可以提升

把办公需求拆成输入、步骤和验收条件；学习给 AI 设定文件范围、确认点和权限边界。

学习价值

7.7/10

推荐理由

官方仓库有 Windows/macOS 客户端且近期仍在更新；使用需配置模型 API，桌面 Agent 有文件操作能力，建议从空文件夹开始。

03 / AI知识管理AI + KNOWLEDGE

Lilbee｜给 Obsidian 笔记装上本地 AI

tobocop2/obsidian-lilbee ↗
一句话介绍

Obsidian 插件，可用本地模型搜索笔记、PDF 和网页资料，回答时附来源，适合搭建自己的可追溯知识库。

普通人使用场景

把公开的 AI 入门文章或 PDF 放进笔记库，问一个具体问题，再顺着引用回原文核对。

小白体验步骤

安装 Obsidian→设置→第三方插件搜索 lilbee→按向导下载本地服务和模型。首次模型下载较大；建议 16GB 内存，不需要 API Key。

可以提升

练习整理资料、针对资料提问并沿引用回到原文，建立有证据的公众号选题研究流程。

学习价值

7.2/10

推荐理由

可从 Obsidian 社区插件商店安装，默认本地处理；目前约 10★、由单人维护，社区验证有限，首次模型下载需要时间和空间。

04 / AI创作与内容AI + CREATION

OpenMAIC｜把主题变成互动课堂

THU-MAIC/OpenMAIC ↗
一句话介绍

输入主题或资料，生成多 AI 角色互动课堂，包含讲解、问答和活动，并可导出 PPTX 或离线 HTML。

普通人使用场景

把公众号选题改成一节短课，让 AI 生成讲解、测验和互动演示，再检查事实是否准确。

小白体验步骤

先打开在线演示，在「发现」浏览课程；自行生成课堂需按页面要求登录并配置模型服务。自托管还要 Node.js 22.19、PostgreSQL 和模型 API Key。

可以提升

把主题拆成讲解、练习和反馈环节，练习设计教学内容；对 AI 给出的知识点回查来源。

学习价值

8.8/10

推荐理由

README 提供在线演示及 PPTX/HTML 导出；GitHub 当前约 41.2k★，10 月 18 日发布 v1.2.1。自建课堂仍需模型服务。

05 / AI生活实验室AI + LIFE

MCP Music Studio｜和 AI 一起做音乐

linxule/mcp-music-studio ↗
一句话介绍

把 AI 助手接入音乐工作台：按描述生成可播放、可编辑的曲谱或节奏，还能边试听边改并导出音频。

普通人使用场景

描述一段轻快的背景音乐，试听后继续要求“慢一点”或“加鼓点”，感受 AI 修改如何改变旋律。

小白体验步骤

在支持 MCP 的 Claude 等助手中添加 https://music-studio.linxule.com/mcp，再描述想要的旋律；页面未发声时点播放。需有可用的 AI 助手账号，无需本机安装。

可以提升

把情绪和审美写成具体音乐要求，再边听边调整；理解生成式 AI 的创作边界，并检查分享内容与授权。

学习价值

7.7/10

推荐理由

官方 README 提供免本地安装的托管 MCP 地址；仓库约 75★、282 次提交，体验前提是已有兼容 MCP 的 AI 助手。
