01 / AI + 数据分析AI + DATA

生财有迹：把个人资产做成一张能看的看板

nicejade/wealth-tracker ↗
一句话介绍

本地记下存款、基金、股票、公积金，自动画趋势图和占比图，还能让 AI 给一段财务建议。

普通人使用场景

发了工资想知道钱散在哪些账户、这个月总资产涨没涨，又不想为记账软件开会员的人。

小白体验步骤

先开在线演示 fund.lovejade.cn（模拟数据、免注册）；想长期用就下 Windows 安装包或 mac 包，装完打开即是完整服务；AI 建议要自己在设置里填 OpenAI 兼容 Key。

可以提升

练习把零散账户归成指标、用趋势线和占比图讲出结论——这就是最朴素的看板思维。

学习价值

8/10

推荐理由

数据留在本机、装完就能用；不足是没有表格导入，AI 建议要自备模型 Key。

02 / AI办公自动化AI + WORKFLOW

会译 HuiYi：Windows 上的实时字幕与 AI 会议纪要

LingyiChen-AI/huiyi ↗
一句话介绍

开会时在旁边听：实时字幕、自动翻译、自动分出谁在说话，会后按模板写好纪要和待办。

普通人使用场景

边开会边记笔记手忙脚乱、听外语分享跟不上、会后还得补纪要的上班族。

小白体验步骤

下 HuiYi-Setup.exe 安装（Win10/11 x64，不要管理员权限），首次启动会下约 260MB 本地识别模型；点托盘图标才开始收听；AI 纪要需在设置里填大模型 Key，不填也能出字幕和记录。

可以提升

练会议结构化：从一堆口语里摘出议题、结论、待办，并用模板固定下来。

学习价值

9/10

推荐理由

语音识别和发言人区分都在本机跑，录音不上传；限制是只有 Windows，纪要要自备模型 Key。

03 / AI知识管理AI + KNOWLEDGE

Forsion：笔记、PDF、日历摆在一张桌上的第二大脑

Changan-Su/Forsion ↗
一句话介绍

本地优先的第二大脑：笔记就是磁盘上的 Markdown，AI 先读你的文件再回答，答案能存成卡片或看板。

普通人使用场景

资料散在笔记、PDF 和聊天记录里，想让它读完再回答问题，又不愿全传上云的人。

小白体验步骤

先开网页版 ai.forsion.net 试（免安装）；长期用就下 Forsion-2.14.2-x64.exe（约 435MB）或 mac 包，再在设置里接自己的 OpenAI 兼容 Key 或本地 Ollama。

可以提升

练「带来源的问答」：看它引用了哪个文件，判断这个答案能不能用。

学习价值

8/10

推荐理由

文件全在本地、随时可导出，适合长期养；限制是安装包不小，第一次要花时间理清模型设置。

04 / AI创作与内容AI + CREATION

ALH Pro：本机跑的老照片修复、抠图、补帧工具箱

AlLHHH/ALH-Pro ↗
一句话介绍

一个 Windows 桌面工具，把模糊照片超分、一键抠图、视频补帧、人声分离全放在本机做完。

普通人使用场景

做图做视频缺素材：老照片糊、头像要去背景、动漫视频卡顿、想把歌声和伴奏分开。

小白体验步骤

去 alhpro.cn 下 ALHPro_v1.4.10_Setup.exe（约 764MB）安装，要抠图再勾选 1.4GB 模型包；选功能、拖素材、调参数、开始，没独显会自动走 CPU（慢）。

可以提升

练一套可复用的素材流程：先修清晰度再抠图，最后统一尺寸和格式。

学习价值

8/10

推荐理由

全本地、免费、中文界面，素材不外传；限制是只有 Windows，视频超分没有独显会很慢。

05 / AI生活实验室AI + LIFE

NabyScape：屏幕边上的音乐岛和同步歌词条

BillyNabil/nabyscape ↗
一句话介绍

屏幕边缘一个小岛：显示正在放的歌、同步歌词、音量与输出设备，还能当时钟和电池看板用。

普通人使用场景

写东西时想瞟一眼歌词、切歌不想切回播放器、桌面又不想被大窗口占满的人。

小白体验步骤

下 NabyScape-win-x64-Setup.exe（约 211MB）装上，拖到屏幕边上即可；歌词自动从 LRCLIB 等源匹配；AI 伴侣是可选项，要填自己的模型 Key。

可以提升

练桌面信息分层：哪些信息值得常驻屏幕边缘，哪些不该打断手上的事。

学习价值

7/10

推荐理由

让电脑顺手一点的小工具，装完就能玩；限制是只支持 Windows，AI 部分要自备 Key。
