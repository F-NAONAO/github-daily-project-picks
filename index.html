01 / AI + 数据分析AI + DATA

AI Analyst：上传 CSV 就能聊出图

e2b-dev/ai-analyst ↗
一句话介绍

把 CSV 丢进去，用大白话提问，它自己写代码算数据、出可交互图表，还能接着追问。

普通人使用场景

月底拿到几千行销售表，不想学透视表，只想问一句「哪个区域卖得最好」并立刻看到图。

小白体验步骤

打开 ai-analyst.e2b.dev，点上传选一个 CSV，问「按月汇总销售额并画折线图」。在线版免安装；自己部署要 E2B 和 Together/Fireworks 的 Key，都要绑卡。

可以提升

练怎么把业务问题问清楚、怎么看懂生成的 Python 代码和图表口径

学习价值

7/10

推荐理由

零安装体验「对话式分析」全流程，比背函数快。限制：底层是 Llama 3.1，中文表头和复杂口径会算错，结论必须自己对一遍。

02 / AI办公自动化AI + WORKFLOW

PasteMD：AI 回答一键粘进 Word

RICHQAQ/PasteMD ↗
一句话介绍

把 Markdown 和网页里的 AI 对话整段粘到 Word、WPS、Excel，标题、表格、代码块格式自动还原。

普通人使用场景

让 AI 写好周报或方案，复制到 Word 变成一堆 ## 和竖线，手动排版半小时还不够。

小白体验步骤

到 pastemd.richqaq.cn 或 Releases 下安装包（Windows 选带 pandoc 的 exe，macOS 用 dmg），装好后复制 AI 回答，按快捷键直接粘。

可以提升

学会用 Markdown 组织内容，把 AI 产出直接变成能交出去的文档

学习价值

9/10

推荐理由

五千多星，天天被写材料的人用，专治排版返工。限制：只解决「粘进来」这一步，内容还得自己想；嵌套表格偶尔要手动微调。

03 / AI知识管理AI + KNOWLEDGE

Reviva：装在电脑里的本地 NotebookLM

mingchen666/Reviva ↗
一句话介绍

把课件、PDF、笔记放进本地资料库，AI 只基于你的资料问答、写笔记、出闪卡和思维导图。

普通人使用场景

转行学数据分析，资料散在十几个 PDF 和网页里，想要一个能问「我这些资料里到底怎么说」的地方。

小白体验步骤

从 Releases 下 Windows exe 或 macOS dmg 安装，在设置里填一个模型 Key（支持 OpenAI 兼容接口或本地 Ollama），再把资料拖进知识库。

可以提升

练资料归档、带来源提问、把问答结果沉淀成自己的笔记

学习价值

8/10

推荐理由

桌面端装完即用、数据留本机，比上传云端踏实；限制是要自己配模型 Key，资料多时首次建索引要等几分钟，功能偏多要摸索。

04 / AI创作与内容AI + CREATION

妙幕 SmartSub：视频字幕一条龙

buxuku/SmartSub ↗
一句话介绍

本地语音转字幕、翻译、AI 配音与声音克隆、字幕烧进画面，一个桌面软件全包了。

普通人使用场景

自己录了课程或口播视频，想加中英双语字幕、配个旁白，又不想按月买剪辑软件。

小白体验步骤

官网或 Releases 下 Windows exe / macOS dmg 安装，拖进视频选本地 Whisper 模型（免费，首次要下模型），出字幕后翻译、导出或烧字幕。

可以提升

练字幕时间轴校对、批量处理多个视频、给内容做多语言版本

学习价值

9/10

推荐理由

近六千星的老牌工具，离线跑不花订阅费，批量处理省事。限制：本地转写吃 CPU/GPU，长视频慢，模型首次下载好几个 G。

05 / AI生活实验室AI + LIFE

拉片笔记：把一部电影拆成结构图

bkingfilm/lapian-notes ↗
一句话介绍

导入电影自动抽帧配字幕，打包丢给 AI 分析，回来生成剧情泳道、结构树和观众情绪曲线。

普通人使用场景

周末想认真看一部片，或者自己拍短视频想学叙事节奏，结果看完只记得「挺好看」。

小白体验步骤

先开 bkingfilm.github.io/lapian-notes 在线试用，导入 MP4 边播边记；要自动转码和搜字幕就下 Releases 解压，Windows 双击 run.bat。

可以提升

练结构化看片：分段落、找关键节拍、看情绪起伏，再反哺自己的内容

学习价值

8/10

推荐理由

不需要 API Key，把分析包丢给手边任意 AI 就行，全流程本地。限制：AI 只做辅助，段落和节拍还得自己判断，长片抽帧挺占硬盘。
