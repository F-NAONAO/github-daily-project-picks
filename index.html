01 / AI + 数据分析AI + DATA

SuperSonic：像聊天一样问数据的国产 BI 平台

tencentmusic/supersonic ↗
一句话介绍

腾讯音乐开源的 AI+BI 平台，把数据表配置好后，用自然语言提问就能得到查询结果和图表，不需要写 SQL。

普通人使用场景

团队想看'这个月各区域销量对比'这类问题，传统 BI 要拖控件写查询，用它直接问就行，适合向业务同事开放自助分析。

小白体验步骤

需要 Docker 一键部署后用浏览器访问（约 30 分钟）；先把示例数据集接入，再试官方文档里的提问示例，跑通后再连自己的库。

可以提升

练习把业务问题表述成清晰的数据问题，理解'语义层'为什么能让 AI 问数更准。

学习价值

8/10

推荐理由

国产 Chat BI 里社区最活跃的项目之一，问答体验成熟；需要 Docker 部署，对纯小白有一道安装门槛，建议先跟官方文档走。

02 / AI办公自动化AI + WORKFLOW

OpenManus：开源全能 AI 智能体，一句话派活儿

FoundationAgents/OpenManus ↗
一句话介绍

近六万星的全能智能体框架，给它一个任务，它会自己规划步骤、操作浏览器、处理文件、写代码，全程可见执行过程。

普通人使用场景

批量收集竞品资料并汇总成文档、自动填一堆重复的网页表单、让 AI 自己跑完一轮数据收集——这类多步骤杂活可以交给它。

小白体验步骤

需要先装 Python，再用 uv 一条命令安装，配置大模型 API Key 后在终端运行；按官方 README 的示例任务跑通第一次约需半小时。

可以提升

理解智能体'规划-执行-观察'的工作循环，学会把模糊需求拆成它可执行的明确指令。

学习价值

8/10

推荐理由

OpenManus 系是最火的开源智能体之一，社区活跃、任务能力强；命令行启动对纯小白有门槛，复杂任务也费 API 额度。

03 / AI知识管理AI + KNOWLEDGE

AFFiNE：白板+文档+表格一体的开源知识库

toeverything/AFFiNE ↗
一句话介绍

开源知识管理平台，文档、画布白板、多维表格无缝混排，内置 AI 助手帮你写作、整理和总结。

普通人使用场景

做项目资料库、读书笔记或个人 Wiki，需要文档和白板混着用、还想让 AI 帮忙整理要点时，它比 Notion 更自由。

小白体验步骤

官网注册可直接用云端版（免费额度够体验），或下载桌面版本地部署；新建一页文档，试试 AI 续写和'选中内容让 AI 总结'。

可以提升

掌握'文档+白板'混排的知识组织方式，练习用 AI 辅助提炼和归档自己的资料。

学习价值

9/10

推荐理由

七万多星、今天还在更新的明星项目，本地化部署可保证数据私有；AI 高级功能部分收费，本地完整部署需要 Docker。

04 / AI创作与内容AI + CREATION

MoneyPrinterTurbo：一个主题生成一条高清短视频

harry0703/MoneyPrinterTurbo ↗
一句话介绍

输入主题或关键词，AI 自动写文案、配素材、生成字幕配音，一键产出高清短视频，14 万多人星标。

普通人使用场景

想做口播类、科普类短视频但不会剪片子：给它一个选题，几分钟出一版成片草稿，再简单调整就能发。

小白体验步骤

提供 Windows 一键安装包和 Docker 两种方式；装好后填一个大模型 API Key，输入主题选好比例（竖屏/横屏）点生成即可。

可以提升

理解 AI 视频生产的流水线：文案、素材、配音、字幕各环节怎么自动衔接，练习改 prompt 控制成片风格。

学习价值

9/10

推荐理由

14.5 万星的现象级项目、今天仍在更新，中文支持好；素材来自免费素材库可能撞图，出片质量取决于所选模型和素材匹配度。

05 / AI生活实验室AI + LIFE

anx-reader：带 AI 助手的开源电子书阅读器

Anxcye/anx-reader ↗
一句话介绍

开源电子书阅读器，支持 EPUB、PDF、mobi 等主流格式，内置 AI 能划词翻译、解释和总结正在读的内容。

普通人使用场景

囤了一堆电子书没时间啃：用它读书时选中难懂的段落让 AI 立刻解释，读外文书划词翻译，读完还能让 AI 总结要点。

小白体验步骤

官网下载 Windows、macOS 或 Android 版安装即可，导入一本 EPUB 试试划词 AI 解释；数据支持 WebDAV 同步。

可以提升

养成'边读边问'的 AI 阅读习惯，用 AI 摘要降低长书的入门门槛。

学习价值

8/10

推荐理由

九千多星、中文界面、界面清爽上手快，AI 能力直接内置无需折腾；iOS 版暂缺，AI 功能需配置自己的模型接口。
