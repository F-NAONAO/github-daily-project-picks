01 / AI + 数据分析AI + DATA

WrenAI：用大白话问数据库，直接出图表

Canner/WrenAI ↗
一句话介绍

开源的 AI 数据分析平台（GenBI），把公司的表接进去后，用自然语言提问就能生成 SQL、查询结果和可视化图表。

普通人使用场景

公司数据躺在数据库里，你不会写 SQL 又不好意思总麻烦技术；有了它，直接问'上个月哪个渠道销售额最高'就行。

小白体验步骤

官网提供云服务可直接注册试用；本地部署需要 Docker，第一步建议先注册云端版，把自己的 CSV 或示例库连上体验提问。

可以提升

练习用准确的业务语言描述数据问题，顺便看 AI 生成的 SQL，慢慢看懂查询逻辑。

学习价值

9/10

推荐理由

一万八千星、今天还在更新的明星项目，'问题变图表'的体验对小白非常友好；连真实业务库需要懂一点权限配置。

02 / AI办公自动化AI + WORKFLOW

Agent TARS：让 AI 替你操作电脑的桌面助手

bytedance/UI-TARS-desktop ↗
一句话介绍

字节开源的桌面 AI 智能体，装好后给它一句话任务，它能自己打开浏览器、点按钮、填表格，像真人一样操作电脑。

普通人使用场景

每天要打开一堆网页查数据、复制粘贴整理资料、批量下载文件，这类'人肉操作'可以试着交给它跑一遍。

小白体验步骤

到 GitHub Releases 下载 Windows 或 macOS 安装包，装上后配置一个模型的 API Key（支持火山方舟、OpenAI 等）即可下达任务。

可以提升

理解'计算机操作智能体'能做什么、做不了什么，学会把任务拆成 AI 能执行清楚的指令。

学习价值

8/10

推荐理由

近四万星标，把前沿的屏幕理解模型做成了人人能装的桌面应用；需要自备模型 API Key，复杂任务仍需盯着它做。

03 / AI知识管理AI + KNOWLEDGE

思源笔记：本地优先、AI 一起干活的笔记工作台

siyuan-note/siyuan ↗
一句话介绍

开源笔记软件，数据存在自己电脑里，块级编辑 + AI 助手，支持让 AI 帮你整理、续写和问答。

普通人使用场景

担心云端笔记隐私、又想要 AI 帮忙整理资料：日常记录、读书笔记、工作文档都放进去，让 AI 基于你的笔记回答问题。

小白体验步骤

官网下载对应系统版本安装即用，个人使用免费；在设置里配置 AI 接口（或插件市场装 AI 插件）就能开始用。

可以提升

养成块级笔记和双链关联的知识管理习惯，学会让 AI 在自己的资料范围内做整理和问答。

学习价值

9/10

推荐理由

四万七千星、今天还有提交的国产开源项目，中文体验一流、隐私优先；AI 能力需要自己配置接口，部分高级功能付费。

04 / AI创作与内容AI + CREATION

Banana Slides：一句话生成一整套 PPT

Anionex/banana-slides ↗
一句话介绍

国产开源 AI PPT 应用，输入主题或大纲，几分钟生成整套幻灯片，支持上传模板照着做，导出可编辑的 pptx。

普通人使用场景

明天要交分享 PPT 只有标题没时间排版；让它先出一版能用的，再在成品上改字改图，省掉从零排版的时间。

小白体验步骤

有在线站点可直接体验，也可本地部署；输入主题或粘贴大纲，生成后一键导出可编辑的 pptx 文件。

可以提升

练习用大纲和提示词表达清楚一份演示的结构，掌握 AI 初稿加人工精修的做 PPT 新流程。

学习价值

9/10

推荐理由

社区非常活跃（三天前还在更新），中文体验好，导出的是可编辑 PPT 而非图片；生成质量依赖所选的图像模型。

05 / AI生活实验室AI + LIFE

Upscayl：免费把模糊老照片变清晰

upscayl/upscayl ↗
一句话介绍

开源 AI 图片放大工具，Windows、macOS、Linux 都有桌面版，完全离线，拖图进去一键变清晰。

普通人使用场景

手机里的老照片糊了、网上存的图太小没法打印、微信传图被压缩，都可以用它放大两到四倍抢救一下。

小白体验步骤

官网 upscayl.org 下载对应系统的安装包，装好后把图片拖进窗口，选好倍数点 Upscayl 等几秒即可。

可以提升

理解 AI 超分辨率的实际边界：什么图救得回来、什么图救不回来，积累修图的第一手手感。

学习价值

8/10

推荐理由

五万多星标的老牌项目，免安装门槛、免联网、免付费，是普通人最容易出成果的 AI 工具之一；对极度模糊的照片效果有限。
