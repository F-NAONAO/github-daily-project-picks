01 / AI + 数据分析AI + DATA

Data Formulator｜让 AI 陪你边问边看数据

microsoft/data-formulator ↗
一句话介绍

微软研究院开源的可视化分析工具：导入 CSV、Excel 等数据，用自然语言追问，并把分析过程整理成可编辑图表和报告。

普通人使用场景

拿到月度销售表，想比较地区走势或找异常，不必先会 SQL；用自己的话提问，再检查图表和结论。

小白体验步骤

从官方 GitHub Releases 下载 Windows/macOS 桌面版，导入 CSV 后问“各地区月销售额怎么变化”。AI 分析需配置模型服务（Ollama 或兼容 API）；桌面预览版未签名，只从官方仓库下载。

可以提升

把业务问题拆成分析问题；核对口径、图表与 AI 结论；把探索过程整理成报告。

学习价值

7.5/10

推荐理由

Microsoft Research 项目，约 17.6k 星；8 月 15 日发布 0.8 beta，增加统一分析流程和数据源。上手门槛高于纯网页工具。

02 / AI办公自动化AI + WORKFLOW

Dify｜把重复工作连成 AI 流程

langgenius/dify ↗
一句话介绍

用可视化画布把“收集材料—AI 处理—检查—输出”连成流程，可用于周报整理、材料摘要、邮件草稿或表格归纳。

普通人使用场景

每周把几份材料整理成统一格式的会议周报或公众号选题，先让 AI 汇总，再由自己检查事实和表达。

小白体验步骤

打开 Dify Cloud 注册，选 Workflow 模板，把示例文字换成自己的短材料并试运行；官方沙盒含 200 次免费 GPT-4 调用。换其他模型通常要配置服务商或 API Key。

可以提升

拆解重复工作；设计输入、检查步骤和输出格式；学会让 AI 按流程做事。

学习价值

8.5/10

推荐理由

GitHub 约 157.5k 星，官方组织页显示 10 月 5 日仍有更新；Dify Open Source License 基于 Apache 2.0 并附带额外条件。

03 / AI知识管理AI + KNOWLEDGE

AnythingLLM｜让 AI 帮你读自己的资料

Mintplex-Labs/anything-llm ↗
一句话介绍

Windows、macOS 桌面 AI 助手；把 PDF、Word 等资料放进工作区后，可以围绕资料提问并查看引用来源，也能连接本地或云端模型。

普通人使用场景

把行业报告、公众号素材或课程讲义放进一个工作区，提问“这几份资料对同一个问题分别怎么说”。

小白体验步骤

下载 Windows Desktop 安装包，按个人用户方式安装；新建工作区，拖入一份 PDF 后提问。可用内置 Ollama 本地模型；首次使用需要下载模型，云端模型需自己的 API Key。

可以提升

整理个人资料；用来源核对 AI 回答；建立可复用的主题知识库。

学习价值

9/10

推荐理由

MIT 开源，约 66.9k 星；仓库 10 月 9 日仍有更新，v1.17 加入模型管理和新手引导改进。

04 / AI创作与内容AI + CREATION

ComfyUI｜用现成模板做图和视频

Comfy-Org/ComfyUI ↗
一句话介绍

开源 AI 创作工具，可用现成工作流生成或编辑图片、视频、音频；既能本机运行，也有云端版本。

普通人使用场景

为公众号试做一张封面，或把图片做成短视频；先套用模板，再改提示词、参考图和输出尺寸。

小白体验步骤

从官方页面下载 Comfy Desktop，安装后在模板库选 Text to Image 教程试做。模型文件会占用不少磁盘；本机生成强烈建议有独立显卡，也可选付费 Comfy Cloud。

可以提升

练习提示词、参考素材和生成结果的迭代；理解一份作品怎样由多个步骤组成。

学习价值

7.5/10

推荐理由

ComfyUI 桌面端仓库 10 月 6 日仍有更新；官方称桌面版是新手最简单入口，并提供模板和教程。模型和显卡是主要门槛。

05 / AI生活实验室AI + LIFE

Folia｜让歌词变成沉浸式音乐画面

chthollyphile/folia-major ↗
一句话介绍

支持本地音乐、网易云、酷狗等来源的歌词播放器；可全屏看歌词动画，并按歌曲情绪生成视觉主题。

普通人使用场景

听歌时打开全屏歌词，让背景配色和歌词氛围随音乐变化；也可以导入自己的本地歌曲。

小白体验步骤

从 GitHub Releases 下载 Windows 版，导入本地歌曲或连接音乐来源；先试歌词动画。想体验 AI 主题，再在设置填 Gemini 或兼容模型 API Key。

可以提升

体验 AI 如何把文字与情绪转成视觉表达；观察提示词、歌词和生成主题之间的关系。

学习价值

8.5/10

推荐理由

GitHub.Locker 统计其 10 月 11 日单日新增约 565 星；9 月 26 日发布 v0.7.9，提供 Windows/macOS 安装包。
