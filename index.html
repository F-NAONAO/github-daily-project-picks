01 / AI + 数据分析AI + DATA

OfficeAI.Chat：Excel/WPS 里的 AI 表格助手

OfficeAIWork/ExcelGPT ↗
一句话介绍

装进 Excel 和 WPS 的 AI 插件：大白话生成公式、做数据处理、出图表、翻译润色，学习成本很低

普通人使用场景

不会写 VLOOKUP、想批量整理一列文本又怕改坏表的时候，直接用大白话说需求，它在表格里帮你干

小白体验步骤

关闭 Excel/WPS → Releases 下载 Windows 版（约 122MB）→ 解压运行 setup.exe → 重启 Excel 按向导确认安装 → 按教程启用 VBA 宏 → 登录官方模型服务（限时免费）

可以提升

练习用大白话描述表格需求，顺手看懂它生成的公式逻辑

学习价值

8/10

推荐理由

把 AI 搬进天天在用的表格软件，不用记公式就有处理思路；限时免费需注册账号，专有软件，个别电脑建议先关杀毒再装

02 / AI办公自动化AI + WORKFLOW

识屏 Shiping：截一下屏幕，AI 就看懂

ooboqoo/shiping ↗
一句话介绍

常驻后台的截屏问答工具：框选题目、代码、报错、图表、外文，快捷键一按就有解答，开会还能实时给提示

普通人使用场景

看不懂报表图表、读英文文档卡壳、开会想抓重点又怕打字慢，框一下屏幕就有答案和要点

小白体验步骤

Releases 下载 Windows 版 setup.exe（约 119MB）→ 首次打开填 API 地址和 Key（默认配好 DeepSeek，充几块钱就能玩很久）→ Ctrl+Alt+S 框选识别

可以提升

练习把 AI 当随叫随到的屏幕讲解员，学会自己配 API Key 和换模型

学习价值

9/10

推荐理由

开源免费、装完即用，截屏问 AI 是最直觉的入门方式；需自备 API Key，语音模式另配阿里百炼，macOS 暂只支持 Apple 芯片

03 / AI知识管理AI + KNOWLEDGE

FlyMD：本地优先的 AI 笔记本

flyhunterl/flymd ↗
一句话介绍

轻量 Markdown 笔记软件：免费内置 AI 助手、知识库语义搜索、PDF 高精度解析、待办推送，数据全在本机

普通人使用场景

想搞本地第二大脑又怕折腾：记笔记、存资料、让 AI 帮你润色改写，还能对整个笔记库直接提问

小白体验步骤

Windows 一行命令 winget install flyhunterl.FlyMD，或 Releases 下 9MB 安装包；macOS 需右键打开绕过签名提示；内置免费模型开箱即用

可以提升

练习 Markdown 写作习惯，学会用 ::关键词 对笔记库做语义搜索

学习价值

8/10

推荐理由

免 Key 也有 AI 可用，本地优先隐私可控，全平台支持；功能靠插件拼装需逐个开启，macOS 首次打开要手动放行

04 / AI创作与内容AI + CREATION

Goink：专治 AI 健忘的长篇小说写作台

sigpanic/goink ↗
一句话介绍

桌面 AI 写作系统：角色、伏笔、剧情弧线全记着，写完自动自查，几十万字里按意思搜前文

普通人使用场景

想用 AI 写长篇网文又怕它写到第五章忘掉设定：把大纲交给它，AI 写你审，每次改动有 Diff 可回退

小白体验步骤

Releases 下载 Windows 安装包（约 62MB，无需 Python/GPU）→ 新建小说 → 填一个 LLM API Key（内置 DeepSeek/GLM 模板）→ 让它先写第一章试试

可以提升

练习给 AI 喂设定、管理长篇创作流程，直观理解 Agent 自动维护状态

学习价值

9/10

推荐理由

本地语义搜索和伏笔追踪是长篇创作的真痛点，全中文界面上手快；要自备 API Key，写长文 token 消耗不小，未签名安装需手动放行

05 / AI生活实验室AI + LIFE

一饭封神：今天吃什么，AI 说了算

liu-ziting/what-to-eat ↗
一句话介绍

AI 菜谱生成网站：报食材选菜系，生成专业菜谱、营养分析、配酒建议，还能一键出菜品效果图

普通人使用场景

冰箱里剩几样菜不知道怎么搭、想给家人换口味，让 AI 现场编一份带步骤和营养分的菜谱

小白体验步骤

浏览器打开演示站 → 点设置图标填自己的 API Key（文本模型 + 智谱 CogView 生图）→ 选食材和菜系点生成，菜谱可本地收藏

可以提升

体验提示词和模型选择怎么影响生成质量：换个模型或调温度，菜谱风格立马不同

学习价值

7/10

推荐理由

开源、在线即开即玩，做饭场景人人相关；演示站也要填自己的 Key，生图要等十几秒，本地跑需 Node.js 18+
