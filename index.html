01 / AI + 数据分析AI + DATA

ADA｜每个数字都能看见怎么算出来

saineshnakra/automated-data-analyst ↗
一句话介绍

上传 CSV/Excel，无代码生成趋势、分组、异常提醒和预测；指标由 pandas 计算，并展示计算过程。

普通人使用场景

用销售、客服或城市公开数据找趋势与异常，再检查每个数字怎么算，练习验证数据结论。

小白体验步骤

打开在线演示→点 Try a sample dataset 选内置合成样例→切换时间和分组看指标。无需注册或 API Key。上传自有文件会传到演示服务器，勿用敏感表格。

可以提升

练习把业务问题拆成指标、趋势和分组，并回看计算细节，养成 AI 提线索、人核证据的分析习惯。

学习价值

9.1/10

推荐理由

GitHub 当前约 30★、11 forks、114 commits；README 提供免注册演示和合成样例，并强调可查看数字计算方法。

一句话介绍

办公 AI Agent 原型，可把任务拆成步骤、生成和编辑文档，并用图形界面查看执行过程。

普通人使用场景

可以提升

练习把办公需求拆成输入、步骤、输出和人工检查点，了解 Agent 执行本机操作前需要哪些权限控制。

6.8/10

03 / AI知识管理AI + KNOWLEDGE

SourceWeft｜把资料、引用和 AI 工作放在一处

SourceWeft/SourceWeft ↗
一句话介绍

把 PDF、网页和笔记放进知识工作台，AI 可据此回答并给出可回查引用，也能整理成报告、演示和学习资料。

普通人使用场景

把公开的 AI 入门文章或课程资料整理进工作区，问一个具体问题，再点引用核对原文，为公众号选题找证据。

小白体验步骤

下载 Windows 桌面版→建工作区→导入公开 PDF/网页→配置模型服务/API Key 和索引模型→提问并检查引用。模型会处理提交内容，先别导入隐私资料。

可以提升

建立资料归档、针对性提问、沿引用回原文的知识工作流，训练用证据写摘要，而非转述无来源结论。

学习价值

8.2/10

推荐理由

GitHub 当前约 271★、24 forks、928 commits；核心采用 Apache-2.0 并提供 Windows 客户端，实际问答需自选模型/API。

04 / AI创作与内容AI + CREATION

ZPix｜在本地生成和编辑公众号配图

SamuelTallet/ZPix ↗
一句话介绍

本地 AI 图片桌面工具，支持提示词生图、参考图改图、画幅调整和风格管理，输出保存在本机。

普通人使用场景

给公众号文章做封面或插图，改一两个提示词和画幅，对比什么描述更接近想要的画面。

小白体验步骤

需近期 NVIDIA 显卡（建议 RTX 30/40/50、显存 8GB+）或 Apple Silicon。安装 1.1.0 桌面版后输入提示词；模型从 Hugging Face 下载，首次需预留时间和空间。

可以提升

练习把文章主题写成画面描述，观察参考图、画幅和风格词对结果的影响，并人工核对图片文字与细节。

学习价值

7.1/10

推荐理由

GitHub 当前约 127★、27 forks、322 commits；README 有 Windows/macOS 1.1.0 包和 8 个模型，但显卡与内存门槛较高。
