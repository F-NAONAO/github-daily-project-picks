01 / AI + 数据分析AI + DATA

CreatorLab 创作者数据工作台

R0xyHaruhi/CreatorLab ↗
一句话介绍

本地分析你抖音、B站作品的真实表现，出战力图和复盘结论，AI 再给下一条的改进建议

普通人使用场景

自己发短视频想知道哪条为什么火、下一条改什么，靠数据复盘而不是凭感觉

小白体验步骤

装 64 位 Python 3.12 → 下载解压源码 → 双击 start_windows.bat 联网装依赖 → 先看内置示例，不用登录账号

可以提升

学会看核心数据指标、做单点改动并复盘验证

学习价值

7/10

推荐理由

示例数据免登录直接玩；正式用要登录抖音账号并核对作品归属，AI 建议默认关闭需自配云端模型，目前仅 Windows 验收

02 / AI办公自动化AI + WORKFLOW

MyCowork 本机办公数字员工

xhthy00/my-cowork ↗
一句话介绍

桌面 AI 办公 Agent，一句话布置任务，它读你本机文件干活，交付真正的 Word、Excel、PPT 文件

普通人使用场景

周报、汇报材料、整理表格这类重复活，丢给它在窗口里跑，自己盯结果就行

小白体验步骤

Releases 下载 MyCowork.Setup.0.1.6.exe 安装 → 新建任务选模型和工作空间 → 描述任务看交付文件预览

可以提升

练把办公任务拆给 AI Agent 做，管理交付文件

学习价值

7/10

推荐理由

装完即用、数据留本机；但要自备模型（云 API Key 或本地推理），安装包约 367MB，部分连接器标着即将推出

03 / AI知识管理AI + KNOWLEDGE

EasyRead 论文中文伴读器

Edwardxlai/easyread ↗
一句话介绍

本地 PDF 论文阅读器：整篇翻成中文对照读，划线记笔记，还能全库问 AI 且答案带原文出处

普通人使用场景

要啃英文论文或报告但英语吃力，想边读边问 AI、把理解沉淀成自己的笔记

小白体验步骤

Releases 下载安装包（Win 135MB / Mac dmg）→ 拖入 PDF 或填 arXiv 编号 → 设置里配模型 API 开翻译和提问

可以提升

练英文文献精读、文献管理，以及按引文溯源核对 AI 答案

学习价值

8/10

推荐理由

翻译对照划线问答一条龙，数据全在本机，官网有在线试读；翻译和提问需自配模型，纯小白要花几分钟配 Key

04 / AI创作与内容AI + CREATION

BeefTV AI 视频创作画布

glanderness/BeefTV ↗
一句话介绍

视频创作工作台：素材、分镜和模型连在一张画布上，Agent 陪你从创意一路推进到成片

普通人使用场景

想做短剧或解说视频但素材乱、流程断，需要一块能反复改、能积累的地方

小白体验步骤

官网或 Releases 下桌面版（Win setup / mac dmg）→ 设置里连接模型服务填 Key → 在画布上从分镜开始做

可以提升

练 AI 视频工作流：分镜规划、素材组织、成片迭代

学习价值

8/10

推荐理由

2600+ 星、更新很勤，Win/mac 桌面版齐全；软件免费但视频生成要接模型服务按量计费，出片成本要心里有数

05 / AI生活实验室AI + LIFE

DigUp 本机内容语义搜索

ARahim3/DigUp ↗
一句话介绍

用大白话搜电脑里的照片、PDF、录音、视频：描述内容就能找到，全程本地离线处理

普通人使用场景

几万张照片和文件找不到在哪，不用一张张翻，按内容描述直接搜出那一页那张

小白体验步骤

Releases 下载安装包（Win x64 setup / mac dmg，仅苹果芯片）→ 首次下载 865MB 模型并选文件夹建索引 → 快捷键唤起直接搜

可以提升

体验本地语义搜索，理解模型怎么按内容而非文件名找东西

学习价值

8/10

推荐理由

6500+ 星、不传数据无账号；模型 865MB 要先下，Windows 版还是 beta 且安装包未签名需手动放行，Mac 要 14+ 苹果芯片
