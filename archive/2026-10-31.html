01 / AI + 数据分析AI + DATA

DataMagic：把一张表格做成会讲故事的动态图表

HKUSTDial/DataMagic ↗
一句话介绍

香港科大写的数据视频工具：上传 CSV，选一个动效配方，AI 就把它做成带动画、带旁白的图表视频。

普通人使用场景

周会汇报、季度复盘、公众号配图：手里有销售表或问卷数据，需要一条别人愿意看完的图形讲解。

小白体验步骤

打开 datamagic.chat 直接在线体验，传表格、选动效、导出视频；也可在 139 张配方卡里挑效果，把源码交给自己的 AI 助手改。

可以提升

练习把数据翻译成画面：选对图表类型、抓住关键数值、安排讲解顺序。

学习价值

8/10

推荐理由

动态图表比静态截图更有说服力，配方库拿来就能改。限制：在线系统有体验额度，超出要付费；本地跑需要 git 和会写提示词。

02 / AI办公自动化AI + WORKFLOW

MDFlux：把一整个文件夹的 PDF、Word 变成干净 Markdown

ibrahimqureshae/mdflux ↗
一句话介绍

本地桌面小工具，拖进文件夹，批量把扫描件、Word、PPT、Excel 转成带标题和表格的 Markdown。

普通人使用场景

想把资料喂给 AI，可复制出来的文字全是乱的：合同、课件、发票、扫描件的文字抓不准，格式也丢了。

小白体验步骤

到 Releases 下载 windows_x64_full 压缩包（约 257MB），解压双击 MDFlux.exe，首次联网装一次环境，之后完全离线。不用账号和 API Key。

可以提升

学会判断什么格式适合喂 AI，理解 OCR、结构化文本和 token 成本之间的关系。

学习价值

8/10

推荐理由

省掉手工复制粘贴，转出来的 Markdown 结构清楚，AI 读得准也更省钱。限制：目前只有 Windows 版，macOS 还在路线图上。

03 / AI知识管理AI + KNOWLEDGE

EdgeEver：像印象笔记的三栏笔记库，AI 能直接读写

tianma-if/edgeever ↗
一句话介绍

开源的 AI 原生笔记库，经典三栏布局，笔记同时存成 Markdown，AI 助手可以通过 MCP 直接读写你的知识库。

普通人使用场景

笔记散在微信收藏、备忘录和网盘里，想找一句话翻半天；还想让 AI 只根据你自己的资料回答问题。

小白体验步骤

先打开 demo.edgeever.org 看效果（每天重置，别存隐私）；要长期用就下桌面端，再按 README 部署自己的后端（Cloudflare 免费额度或一条 Docker 命令）。

可以提升

练习知识库的结构设计：目录怎么分、笔记怎么写才方便被检索和引用。

学习价值

7/10

推荐理由

数据是自己的 Markdown，不锁定平台，三千星且今天还在提交。限制：得先部署后端，纯小白第一次会卡在 Cloudflare 那几步。

04 / AI创作与内容AI + CREATION

OpenChatCut：能用说话改的本地视频剪辑器

0xsline/OpenChatCut ↗
一句话介绍

对话式 AI 剪辑器，跟它说“去掉停顿、加字幕”，它直接改真实时间线上的片段，改完还能手动继续修。

普通人使用场景

做口播、课程、视频号内容，一小时的素材，手动对轴、去停顿、打字幕最耗时间。

小白体验步骤

到 Releases 下载对应系统的安装包（Windows exe、macOS dmg），装完就能用；本地剪辑不联网，要用 AI 对话就在设置里填一个模型 API Key。

可以提升

练剪辑基本功：多轨时间线、字幕、转场；顺带学会怎么把剪辑意图说清楚给 AI 听。

学习价值

8/10

推荐理由

产出是可编辑的轨道而不是黑盒视频，这点比一键生成实用。限制：还在早期，功能常变；macOS 包未签名；安装包 700MB 起。

05 / AI生活实验室AI + LIFE

yovoice：在自己电脑上做配音、克隆声音、写歌

leemysw/yovoice ↗
一句话介绍

本地 AI 音频工作室：文字转语音、克隆自己的声音、生成带歌词的整首歌，全程离线、按字符不计费。

普通人使用场景

想给视频配个像样的旁白，或者给家人做一首生日歌，又不想按字数付费、不想把声音和文稿传到别人服务器。

小白体验步骤

从 Releases 下载 Windows 的 setup.exe 或 macOS 的 dmg，装好打开，在应用里下载模型（第一次要等一会儿），就能开始生成。无需注册和 API Key。

可以提升

摸清 TTS、声音克隆和 AI 音乐的真实水平，学会调语气、断句和节奏。

学习价值

8/10

推荐理由

一次装好之后不再付费，素材不出本机，两三星且昨天还在更新。限制：模型要下载几个 GB，核显或老机器会很慢；克隆别人声音要授权。
