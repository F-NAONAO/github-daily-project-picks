01 / AI + 数据分析AI + DATA

Datell｜用一句话把 CSV 变成互动报表

aiis2/datell ↗
一句话介绍

中文版本地数据分析桌面工具，导入 CSV/Excel 后用自然语言提问题，生成可交互图表与 HTML、Excel、PDF 等报告。

普通人使用场景

拿公开销售数据问“最近销售下滑在哪些月份、哪个地区贡献最高”，边看图边核对口径。

小白体验步骤

GitHub 仓库 → Releases 下载 Windows 免安装版 1.0.6 → 导入练习 CSV。AI 分析要配置模型 API Key，也可接本地 Ollama；先不要导入公司或个人敏感表。

可以提升

从提问、清洗、图表到报告走一遍；练习先核对指标口径和证据，再接受 AI 结论。

学习价值

8.6/10

推荐理由

中文界面、Windows 免安装版、Excel/CSV 导入和报表导出齐全；当前约 3★/303 次提交，仍属早期工具，AI 需自备模型。

02 / AI办公自动化AI + WORKFLOW

PilotDeck｜把办公任务交给桌面 AI 助手

OpenBMB/PilotDeck ↗
一句话介绍

AI 工作台可接收文件和目标，处理办公文档、Excel、PPT，并展示执行过程与文件成果。

普通人使用场景

把几份公开资料整理成一页汇报或练习表格，观察它怎样分步骤完成并留出复核空间。

小白体验步骤

先开官网在线试玩沙盒看流程；想实际生成，下载 Windows/macOS 客户端并配置模型 API，或本机 Ollama。用公开材料和新建文件夹练习。

可以提升

把需求、素材、输出格式、限制条件写清楚；学习检查 AI 处理文件和数值的过程，确认后再交付。

学习价值

9/10

推荐理由

10 月 15 日发布 2.0，官方提供 Windows/macOS 客户端和互动演示；生成需模型服务，也支持本地 Ollama。

03 / AI知识管理AI + KNOWLEDGE

OpenWiki｜把收藏内容整理成自己的知识库

kdsz001/OpenWiki ↗
一句话介绍

桌面知识管理工具，主动收藏剪贴板文字、图片和网页，再让 AI 归纳成知识页、关系图和周报；数据主库保存在本地。

普通人使用场景

把公众号选题需要的公开文章保存起来，按主题查看 AI 整理的材料，减少资料散落。

小白体验步骤

下载 Windows 安装包→连接 AI 账号或填 API Key→复制并保存一篇公开文章，查看生成的知识页和关联图。初次别导入私密资料。

可以提升

练习筛选资料、建立主题、回看内容脉络，把搜集素材变成可复用的个人知识库。

学习价值

8.8/10

推荐理由

654★、132 forks，提供 Windows/macOS 客户端；AI 需自备账号或 Key。网页读取和翻译默认可能调用 Jina、Google，可在设置关闭。

04 / AI创作与内容AI + CREATION

OpenCreator｜公众号和短视频的 AI 内容工作台

krillinai/OpenCreator ↗
一句话介绍

桌面创作工作台可从选题、链接或文档起草文章、短视频脚本和小红书笔记，也能做图片、配音与视频翻译。

普通人使用场景

给「AI人话铺子」一个主题和公开资料，生成文章提纲，再拆出短视频口播稿供你校订。

小白体验步骤

在仓库 Releases 下载桌面版→按向导复用本机 Codex 登录或配置模型→Dashboard 选“文章写作”，输入主题和公开资料，检查后再导出。

可以提升

把受众、平台、篇幅、口吻和事实来源交代清楚；练习改 AI 初稿，而不是照搬发布。

学习价值

8.8/10

推荐理由

README 列出 10 项可用创作工具；约 13.8k★、支持 43 种界面语言。模型、配音或视频生成服务可能另需额度。

05 / AI生活实验室AI + LIFE

Agent Arena｜看 AI 角色在 3D 世界里互动

sametkabay/agent-arena ↗
一句话介绍

浏览器里的多角色 AI 沙盒：把不同人设放进办公室、森林或太空场景，看角色闲聊，也能和某个角色私聊。

普通人使用场景

用同一个问题分别问不同人设，对比回答如何受角色设定影响，直观感受 AI 角色和多智能体互动。

小白体验步骤

从仓库 README 进入 Live demo，选昵称和地图；要启动 AI 对话，在设置添加 OpenAI/Gemini/Claude 等模型 API Key。先用不含隐私的问题试聊。

可以提升

理解角色设定和 AI 模型如何影响回答；练习给 AI 明确背景、身份与任务，再比较结果。

学习价值

8/10

推荐理由

当前 14★、15 个 Issue、8 个 PR；仓库标注 v0.1 早期预览。在线 Demo 无需下载，云模型交互可能受提供商跨域设置影响。
