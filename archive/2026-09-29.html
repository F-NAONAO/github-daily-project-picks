marimo 响应式分析笔记本

marimo-team/marimo ↗

用纯 Python 保存的响应式 Notebook，单元格依赖自动更新；可用 SQL 查数据、做交互分析，并发布为应用。

上手方式

先在 molab 打开在线 Notebook；本地可安装 marimo 并运行入门教程。内置 AI 助手需自备 API key 或本地模型。

AI 时代的成长点

让 AI 生成分析代码后，用响应式依赖和可复现执行检查结果，练习把探索过程沉淀成可审阅、可复用的分析应用。

Pinvou Agent 桌面工作流

Pinvou/pinvou-agent ↗

将附件、知识库、技能和工具连接到桌面 Agent，让调研、写作和设计任务产出可继续编辑的文件。

上手方式

从 Releases 下载桌面预览版；接入本地 vLLM 或兼容 OpenAI 的模型服务。云模型通常需要 API key。

Univer Workspace 协作工作台

dream-num/univer-workspace ↗

将表格、文档、幻灯片和团队空间放在同一工作台；Agent 在隔离草稿中修改，交由人审核后合并。

上手方式

需 Node.js 24 与 pnpm 11；按 README 启动 Server 和 Browser，再打开本地 5173 端口。Agent 另需模型凭据。

AI 时代的成长点

体验 Agent 修改 Office 内容的隔离草稿与人工合并，学习给 AI 划定权限、验证输出，并保留团队协作中的审阅环节。

YuE2 Studio 本地 AI 作曲

timoncool/YuE2-Studio ↗

在本机输入曲风和歌词生成带人声的歌曲，并查看、编辑乐谱后重新演绎同一段旋律。

上手方式

Windows 10/11 下载 Releases 安装包；建议 NVIDIA 显存至少6GB，首次需下载约4–10GB模型。无需 API key。

AI 时代的成长点

对比同一份歌词在改动曲风、速度和音符前后的成曲，理解生成模型的可控边界；保留乐谱与设置，复盘自己的创作判断。
