01 / AI + 数据分析AI + DATA

Trace｜把新闻报道做成分析关系图

TonF1917/Trace ↗
一句话介绍

把同一事件的多篇报道放在一起，AI标出叙事角度、角色与责任关系，并生成可交互关系图；有中文界面，资料留在本地浏览器。

普通人使用场景

选一个近期新闻，收集两三家媒体的公开报道，比较它们把重点放在哪、归因给谁，再回到原文核对。

小白体验步骤

按中文 README 启动 Windows 版：需 Node.js 并在 app 目录安装依赖；再接 OpenAI 兼容模型，或配置本地 LM Studio/Ollama。初次设置略偏技术。

可以提升

练习从文本中提取信息、比较不同来源的表达，并核对 AI 归纳是否有原文依据。

学习价值

7/10

推荐理由

本周数据可视化方向约新增437星。适合练文本分析和证据核对，但不是传统Excel分析工具，启动与模型配置有门槛。

02 / AI办公自动化AI + WORKFLOW

Dossier｜把求职申请变成可追踪流程

AienTech/dossier ↗
一句话介绍

用一份职业档案生成匹配岗位的简历和求职信，展示技能差距，并跟踪申请进度；它只起草材料，不会替你投递。

普通人使用场景

用虚构资料粘贴一则数据分析岗位描述，对照经历找出缺口，再检查AI草稿是否只用了档案里真实的信息。

小白体验步骤

需要 Docker Desktop；按官方 Compose 指引启动，首次下载约1.7 GB。界面以英文为主；AI需配置本地 Ollama/LM Studio 或云模型。

可以提升

练习拆解岗位要求、把经历写成证据，并检查 AI 是否夸大或编造经历。

学习价值

7.5/10

推荐理由

求职工具本周关注度上升，Dossier近周约新增429星。和数据分析求职场景贴近，但需要Docker，首次部署比普通桌面软件多几步。

03 / AI知识管理AI + KNOWLEDGE

Talorys｜部署在自己账号里的AI备忘助手

rociiu/talorys ↗
一句话介绍

把聊天、笔记、待办和提醒放进一个个人AI助手，部署到自己的 Cloudflare 账号，并可用过往记录辅助回忆。

普通人使用场景

放入一份公开的学习笔记，问“我最近记录过哪些数据分析问题”，再让它把问题整理成复习清单。

小白体验步骤

需 Node.js 22+ 和 Cloudflare 账号；运行官方 npx 部署命令并授权。自带 Workers AI 有用量额度；Cloudflare 会处理发给AI的消息。

可以提升

练习持续记录、整理和回顾知识，观察AI回答依赖了哪些历史信息。

学习价值

7.5/10

推荐理由

AI记忆工具榜新项目，本周约新增1.2k星；个人笔记和提醒集中在一处，但需要登录Cloudflare并完成首次部署。

04 / AI创作与内容AI + CREATION

Textus｜边写边改的AI Markdown编辑器

CatVinci-Studio/Textus ↗
一句话介绍

像普通文档一样写公众号草稿，AI可续写、校对、翻译和调整语气；修改先以建议呈现，可逐句决定是否采用。

普通人使用场景

新建一篇“AI数据分析入门”草稿，让AI找出冗句并提供改法，再逐条选择是否采用，保留自己的表达。

小白体验步骤

下载官方 Windows x64 安装包；在设置中登录或连接模型。支持 DeepSeek、通义千问、Kimi、Ollama 等；云模型可能收费。

可以提升

练习拆分写作要求、迭代修改，并判断哪些AI建议符合自己的表达风格。

学习价值

8.5/10

推荐理由

桌面应用本周约新增420星；有Windows安装包和中文界面，适合直接试写公众号。AI功能需要连接模型，纯编辑可离线使用。

05 / AI生活实验室AI + LIFE

nanoMuse｜跨设备的AI生活搭子

nano-muse/nanoMuse ↗
一句话介绍

可在电脑、手机和浏览器里聊天、记事、设提醒，AI会记住选定的信息；涉及电脑操作时可以先请求批准。

普通人使用场景

记下旅行计划或每周运动目标，请它整理成提醒和一周回顾；第一次先只体验聊天、笔记和提醒。

Windows 10+ 可安装官方桌面版，也可先体验浏览器演示。需登录并选模型；Windows安装包未签名会触发SmartScreen，首次启动可能较慢。

可以提升

练习把生活目标拆成小任务和提醒，并判断哪些个人信息适合交给AI长期记忆。

学习价值

7/10

推荐理由

本周桌面应用榜约新增1.1k星，提供Windows版和跨设备记忆。首次加载可能要等几分钟，下载前先确认来自官方仓库。
