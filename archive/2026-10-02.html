DuckDB 本地分析数据库

duckdb/duckdb ↗

可在本机直接用 SQL 分析 CSV、Parquet 等数据的嵌入式分析数据库，提供命令行和 Python 等客户端。

上手方式

从官网安装 DuckDB 命令行版，打开本地 CSV 或 Parquet 文件执行 SQL；本地分析无需 API key。

AI 时代的成长点

用 AI 生成探索性 SQL，再用 DuckDB 核对字段、过滤条件与聚合结果，练习把自然语言问题变成可复现的分析。

GitHub 于 9 月 28 日发布 v1.5.6 修复版，发布记录列出多位贡献者。

activepieces/activepieces ↗
