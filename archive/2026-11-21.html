01 / AI + 数据分析AI + DATA

格知 AI 表格助手

beiwocaishijia/gezhi-sheets ↗
一句话介绍

在浏览器里开的本地 AI 表格，框选一片数据说句话，它提取、分类、算公式，确认后才写回。

普通人使用场景

把客户留言、订单整理成表格；不会写 Excel 公式；想按供应商汇总金额。

小白体验步骤

装 Node.js 22.13+，下载仓库后双击「启动格知 AI.cmd」，打开 127.0.0.1:8001，填入 DeepSeek 等 API Key，再导入 xlsx。

可以提升

把需求说清楚、用中文描述公式、核对 AI 结果再写入

学习价值

8/10

推荐理由

少见地把 AI 改表做成可预览、可撤销的工作台，不怕它乱改；代价是要自己装 Node、配 Key，纯小白最好有人带。

02 / AI办公自动化AI + WORKFLOW

简历通 ResumeForge

magicapple123/ResumeForge ↗
一句话介绍

本地运行的 AI 简历工作台：排版导出、投递记录、模拟面试都在一个软件里，资料不上传。

普通人使用场景

按岗位改简历、记录投了哪几家、面试前想先练两轮。

小白体验步骤

装 Windows 版 Setup.exe（181MB，也有 mac 包），不用注册；不填模型也能排版导出，要 AI 改写再去设置里选 DeepSeek 预设填 Key。

可以提升

简历结构化表达、按 JD 对齐关键词、让 AI 改但不许编造

学习价值

8/10

推荐理由

内置事实账本能挡住 AI 编经历，顺便管投递进度；官网 demo 只能看不能存，真用得装本地版。

03 / AI知识管理AI + KNOWLEDGE

MrRSS AI 阅读器

DevXDojo/MrRSS ↗
一句话介绍

免费的 AI RSS 阅读器：把公众号、网站、RSSHub 收进一个窗口，自动翻译标题正文并生成摘要。

普通人使用场景

每天十几个信息源散在各处；英文资讯读着累；想先扫摘要挑重点。

小白体验步骤

下 Windows 安装包（也有 mac 和免安装版），加几个 RSS 或 RSSHub 源就能读；AI 摘要在设置里填兼容 OpenAI 的 Key 或接本地 Ollama。

可以提升

搭个人信息源、用摘要做筛选、把好文章同步进 Obsidian 或 Notion

学习价值

8/10

推荐理由

把信息过载压成一份能扫的清单，还能一键进 Obsidian；不配模型只有翻译，摘要得自己出 Key 或跑 Ollama。

04 / AI创作与内容AI + CREATION

Toonflow 漫剧工坊

HBAI-Ltd/Toonflow-app ↗
一句话介绍

开源 AI 漫剧短剧工作台：写剧本、拆分镜、管角色、生图生视频，全在一张无限画布上完成。

普通人使用场景

想把小说片段或一个点子做成 1 分钟漫剧，而不是只做口播。

小白体验步骤

装 Windows 版 Setup.exe（33MB），按引导填文本、图片、视频模型的 API Key，先用自带示例剧本跑一遍分镜。

可以提升

剧本拆分镜、角色一致性管理、生图生视频提示词

学习价值

7/10

推荐理由

22k 星的国产开源项目，装完就能看到成品链路；但视频按秒计费，认真做要备模型额度，也要点耐心。

05 / AI生活实验室AI + LIFE

狸影 LiYing 证件照

aoguai/LiYing ↗
一句话介绍

全程离线的证件照流水线：自动识别人脸、摆正、换底色、按尺寸裁切，还排版成可打印相纸。

普通人使用场景

求职、考试、签证要交不同底色和尺寸的证件照；自己拍一张想直接打印。

小白体验步骤

下 Windows 的 WebUI 整合包（约 190MB）解压，按说明放好抠图模型，运行后浏览器打开界面，拖照片选底色尺寸。

可以提升

证件照规格（一寸二寸、底色）、批量处理、冲印排版

学习价值

8/10

推荐理由

照相馆几十块的事，它本地几秒做完，照片不出电脑；代价是首次要自己下模型，环境比在线工具麻烦。
