God's Eye View｜把地球变成实时可探索的数据仪表盘

bilawalsidhu/gods-eye-view ↗

在浏览器的 3D 地球上叠加航班、船舶、卫星、地震、交通与公共摄像头等公开数据，可跟踪目标、查询数据，还能用语音控制 AI 助手。

02 / 办公自动化WORKFLOW

LobsterAI｜能动手干活的桌面办公 Agent

netease-youdao/LobsterAI ↗

网易有道开源的桌面 Agent，可读本地文件、操作浏览器、处理 Word/Excel/PPT、生成视频与网页研究，还支持定时任务，并能从飞书等 IM 远程下指令。

上手方式

下载 Windows/macOS 客户端，连接可用模型后，给它一个具体任务，例如“分析这份 Excel 并整理成图表”。

AI 时代的成长点

从单轮问答进阶到多 Agent 分工、可复用 Skills/MCP 和定时工作流；还能自己写 Agent 或扩展任务。

GitHub 仓库约 6.1k Stars、近 4,200 次提交；9/27 仍有更新。

Agent Office｜把 AI 编码团队放进 3D 办公室

AgentSystemLabs/agent-office ↗

可走动的卡通 3D 办公室：把 Claude Code、OpenCode 或 Codex 安排到工位，实时看终端、共享 Shell、语音协作，还能在墙上看 Issues/PR。

AI 时代的成长点

把 AI 团队协作变成可观察的工作台；还能扩展不同 Agent、项目工位与任务看板，探索人机协作的新方式。

9/28 发布新版本；项目刚开源，仍在快速迭代。
