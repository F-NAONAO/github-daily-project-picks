OpenSEO 搜索数据分析台

every-app/open-seo ↗

把关键词研究、排名跟踪、竞品、反链和站点审计放在同一工作台，也提供 MCP 让 Agent 读取 SEO 数据。

上手方式

官网可免费试用；自托管可用 Docker，获取实际 SEO 数据须配置按量付费的 DataForSEO API key。

AI 时代的成长点

用同一批关键词和排名数据对比人工分析与 Agent 经 MCP 得出的结论，练习核对指标来源、成本和建议的证据链。

MarkItDown 文档转 Markdown

microsoft/markitdown ↗

把 PDF、Word、Excel、PPT 等办公文件转成 Markdown，方便归档、检索与后续自动处理。

上手方式

安装 Python 后运行 pip install 'markitdown[all]'，再执行 markitdown 文件路径 -o 输出.md；常规转换无需 API key。

AI 时代的成长点

把真实文档转成可检索文本，再逐项检查表格、标题和引用是否保真，学习为 AI 文档流程建立输入质量检查。

WeKnora 团队知识工作台

Tencent/WeKnora ↗

将团队文档组织为知识库，提供检索问答、Agent 多步任务和 Wiki，并支持多工作空间与权限管理。

上手方式

按 README 用 Docker Compose 部署并完成模型配置；可接云模型服务，或另行配置本地 Ollama。

AI 时代的成长点

用一组已知答案的内部文档测试检索、引用和权限边界，练习评估知识库 Agent 的可靠性与可追溯性。

Nuclear 开源音乐播放器

nukeop/nuclear ↗

跨平台音乐播放器，支持搜索、播放列表、插件来源和主题；可选 MCP 接口让本地 Agent 控制播放。

上手方式

从 GitHub Releases 下载 Windows 安装包、macOS dmg 或 Linux 包；播放来源依赖所选插件，MCP 需在设置中启用。

AI 时代的成长点

先手动整理歌单，再尝试通过 MCP 让 Agent 操作播放器，观察工具权限、搜索来源与播放结果是否符合预期。

GitHub 9 月 25 日发布 v1.49.1，提供多个平台的安装包。
