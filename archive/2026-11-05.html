01 / AI + 数据分析AI + DATA

WeLink：把微信聊天记录变成能提问的数据

runzhliu/welink ↗
一句话介绍

把微信聊天记录导入后交给 AI 分析：好友画像、群聊活跃度、关系变化，用大白话直接提问拿洞察。

普通人使用场景

想知道「今年和谁聊得少了」「群里真正活跃的人是谁」，不用一条条翻记录，导入后直接问 AI。

小白体验步骤

先打开 demo.welink.click 在线演示感受效果；自己部署需装 Docker，按官方文档拉起前后端，再按引导导入微信聊天数据库。

可以提升

走一遍「数据导入→清洗→提问分析」的完整流程，理解本地数据怎么安全地交给 AI 做分析。

学习价值

8/10

推荐理由

有可直接点开的在线演示，聊天数据本地优先；但自己部署要装 Docker，纯小白得花点功夫，深度分析还需配置大模型 API。

02 / AI办公自动化AI + WORKFLOW

馆长：会替你干活的本地办公文件 AI 助手

Yoan98/Ncurator ↗
一句话介绍

Windows/macOS 桌面应用，能读取、创建、修改 Word/Excel/PPT，还能联网搜索、跑本地命令、建本地知识库。

普通人使用场景

让它把一堆会议记录整理成周报、批量调整表格格式、把散落资料建成知识库随问随答，改动都有审核记录。

小白体验步骤

去官网 guanzhangai.cn 下载 Windows 或 macOS 安装包，选模型或填自己的 API Key，创建一个「伙伴」后直接交代任务。

可以提升

练习把重复办公活儿拆成清晰的 AI 任务指令，用改动审核和回退功能把关 AI 的文件修改结果。

学习价值

9/10

推荐理由

下载安装就能用，文件改动有人工审核兜底，还支持 WPS 联动定位修改处；完整功能需要自备模型 API Key。

03 / AI知识管理AI + KNOWLEDGE

Smart Second Brain：让 Obsidian 笔记库活起来

s2b-dev/smart-second-brain ↗
一句话介绍

免费开源的 Obsidian 插件：语义搜索、自动分组的知识图谱，接上 AI 后还能帮你读写笔记、画图表。

普通人使用场景

笔记攒了几百篇找不到、看不出去时，用它按「意思」搜笔记，或让 AI 助手基于你自己的笔记回答问题。

小白体验步骤

在 Obsidian 社区插件市场搜 Smart Second Brain 安装启用即可，搜索和图谱零配置马上能用，桌面和手机端都支持。

可以提升

学会用语义搜索和主题图谱整理个人笔记库，再尝试给 AI 助手派任务，让它帮你补全和整理笔记。

学习价值

8/10

推荐理由

不接 AI 也有搜索和图谱可用，数据默认不出本机、无遥测；要解锁完整 AI 助手需自己配置模型和向量模型。

04 / AI创作与内容AI + CREATION

迅排设计：开源在线海报设计器，自带免费 AI

palxiao/poster-design ↗
一句话介绍

类似稿定设计的开源画布编辑器，做海报、公众号封面、电商图，内置免费 AI 生图、AI 文案和一键抠图。

普通人使用场景

公众号头图、活动海报、商品图自己做太费劲，套模板拖拖拽拽，AI 帮你生成文案、抠掉背景。

小白体验步骤

先打开 design.palxp.cn 在线试用；想本地部署需要 Node.js 环境，按 README 跑几条 npm 命令即可跑起来。

可以提升

练习版式设计和模板复用，体验 AI 抠图、AI 文案如何加速出图，进阶可自己部署一套私有设计工具。

学习价值

8/10

推荐理由

在线版能直接玩，开源版功能全、可私有部署还带管理后台；本地部署要装 Node.js，AI 生图风格偏实用而非艺术。

05 / AI生活实验室AI + LIFE

dsh-pet：会吃火锅打瞌睡的 AI 桌面宠物

PC2005-cloud/dsh-pet ↗
一句话介绍

一只带 100 多段动画的桌面宠物，会陪你聊天、念语音、播报余额，还能用 AI 亲手生成专属新宠物。

普通人使用场景

工作时想让桌面上有个小家伙陪着，或者想自己「造」一只宠物：用 AI 视频生成素材，全程可复现。

小白体验步骤

Windows 用户去 Release 下载绿色包 dsh-pet-win-x64.zip，解压双击 exe 就能跑；也支持一行命令装进 DeepSeek Harness。

可以提升

体验 AI 生成动画素材到桌面应用的完整链路，动手做自己的宠物包（pet pack），顺手玩转桌面透明窗交互。

学习价值

8/10

推荐理由

有免安装的独立模式，双击就能养起来；聊天和碎碎念需要接大模型服务，Mac 用户目前只能走插件模式。
