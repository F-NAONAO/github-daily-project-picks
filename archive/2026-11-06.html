01 / AI + 数据分析AI + DATA

Codata：跟数据聊天就能出图表

Mlilion/Codata ↗
一句话介绍

本地优先的桌面 Data Agent：用人话问数据，它帮你写 SQL、跑查询、出图表，还能把结果钉成看板

普通人使用场景

手里一堆订单表、会员表，想知道「哪个渠道转化最好」却不会写 SQL 的运营和数据新人

小白体验步骤

去 Releases 下载 Windows/macOS 安装包，连上数据库或自带示例数据，配一个模型 API Key 或本地 Ollama 就能开问

可以提升

练习把业务问题翻译成数据问题，看懂 SQL、指标口径和图表背后的逻辑

学习价值

8/10

推荐理由

问数、图表、看板、多智能体专家团一整套都在桌面端，链路完整；但要连真实数据源才好玩，第一次配置数据连接要花点耐心

02 / AI办公自动化AI + WORKFLOW

Kojoo Mail：所有邮箱一个收件箱，AI 帮你先读一遍

ekoouu/kojoomail ↗
一句话介绍

Windows/macOS 桌面邮件客户端，QQ、163、Gmail、Outlook 合到一个窗口，每封新邮件 AI 先批注摘要和待办

普通人使用场景

每天在好几个邮箱之间来回切、重要邮件被广告淹没、回英文邮件要先翻译再斟酌的打工人

小白体验步骤

官网或 Releases 下载安装包（约 3MB），添加邮箱账号即可；Gmail/Outlook 浏览器一键授权，AI 用你自己的 API Key

可以提升

学会用 AI 摘要、待办提取和「问邮箱」直接提问，把收件箱变成待办清单

学习价值

8/10

推荐理由

邮件只存本机、AI 不经第三方服务器，隐私省心；AI 功能要自备模型密钥，收 Gmail 需代理但软件会跟随系统代理

03 / AI知识管理AI + KNOWLEDGE

Crow：把电脑里的文档变成会聊天的第二大脑

crow-hq/crow-desktop ↗
一句话介绍

自动找到电脑里的 PDF、Word、表格，整理成互相关联的 Markdown wiki，提问时还带出处引用

普通人使用场景

资料散在桌面、下载和文档文件夹里，想找找不到、想整理又懒得动手的人

小白体验步骤

GitHub 下载 Windows/macOS 安装包，勾选要整理的文件夹，配自己的 OpenRouter 账号，先看预估花费再开始

可以提升

体会「文档自动归档 + 带引用问答」的知识库思路，学着给散乱资料建结构

学习价值

8/10

推荐理由

不需要命令行，点几下就能把一堆旧文档变成能对话的 wiki；模型费用走自己的 OpenRouter 账号，文档多会有成本，注意看预估

05 / AI生活实验室AI + LIFE

Salt & Story：把长辈口述的菜谱做成一本家传菜谱书

ADITYA-KUMAR-2358/salt-and-story ↗
一句话介绍

录一段长辈讲做菜的语音，AI 整理成干净可打印的菜谱并保留原话，最后导出成 PDF 小书

普通人使用场景

想留住爸妈、爷爷奶奶「适量、一小勺」式口传菜谱的人，逢年过节做一本家庭菜谱当礼物

小白体验步骤

打开官网用 Google 账号登录，现场录音或上传语音，Gemma 4 模型整理成菜谱；每天 5 条 AI 整理额度，免费够用

可以提升

体验语音转写加结构化整理的完整流程，学着把口述内容核对成可复用的记录

学习价值

8/10

推荐理由

场景小而暖，网页打开就能试、什么都不用装；需要 Google 登录且国内访问可能要代理，AI 整理有每日免费额度限制
