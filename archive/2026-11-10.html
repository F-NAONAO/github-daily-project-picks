01 / AI + 数据分析AI + DATA

LogiSheets：能用中文指挥的网页 Excel

logisky/LogiSheets ↗
一句话介绍

浏览器里打开的表格，能直接读写 .xlsx，右侧 AI 助手用一句话帮你改公式、算汇总。

普通人使用场景

每月导出的销售表要对账、要加同比环比列，又不想背 Excel 公式。

小白体验步骤

打开 www.logisheets.com，拖进一个 .xlsx 或新建表；点右侧 Watson，在设置里填自己的 OpenAI / DeepSeek Key 就能开聊。

可以提升

表格结构、公式与数据校验，练习把需求说清楚

学习价值

8/10

推荐理由

零安装、中文界面，AI 直接改真表格而不是只给建议；限制是 AI 要自备模型 Key，按量付费。

02 / AI办公自动化AI + WORKFLOW

文小舟：给 WPS 装一个会改文档的 AI

lewis-hui1202/WPS-AI ↗
一句话介绍

WPS 文字/表格/演示/PDF 四端共用的 AI 侧边栏，能直接读写你正在编辑的这份文档。

普通人使用场景

写周报、改格式、照表格数据写分析结论，不想在网页和文档之间反复复制粘贴。

小白体验步骤

到 wps-ai.llteac.cn/download/ 下 Windows 安装包，装完完全退出再重开 WPS，点「文小舟」标签，填一家模型 Key（本地 Ollama 免 Key）。

可以提升

用工具调用的思路指挥 AI 改文档，练提示词和结果核对

学习价值

8/10

推荐理由

少见能把 AI 真塞进 WPS 四端的开源方案，国产模型都能接；限制是必须 WPS 12.x 桌面版，安装时可能要临时关杀软。

03 / AI知识管理AI + KNOWLEDGE

KnowNote：把一柜子 PDF 变成能追问的笔记库

MrSibe/KnowNote ↗
一句话介绍

本地跑的桌面知识库，导入 PDF、Word、PPT，提问时每句答案都带原文出处。

普通人使用场景

准备考证或看行业报告，几十份资料记不住，想知道某句话到底出自哪一页。

小白体验步骤

GitHub Releases 下 knownote-1.5.3-setup.exe，装完把文件夹拖进去；模型填自己的 OpenAI / Claude Key 或本地 Ollama。

可以提升

资料归档、提问式检索、把答案整理成结构化笔记

学习价值

9/10

推荐理由

不用 Docker、不用注册账号，装完就能问，答案能点回原文；限制是嵌入模型首次要下载，老电脑初次索引偏慢。

04 / AI创作与内容AI + CREATION

Beav：一个人的自媒体工作台

Jamailar/Beav ↗
一句话介绍

本地优先的内容工作台，从热搜选题、AI 写稿配图到口播剪辑，一个软件走完。

普通人使用场景

一个人运营小红书或公众号，找选题、出图、剪口播要开五六个工具来回倒素材。

小白体验步骤

beav.pro/download 下 Windows 安装包（x64 约 98MB），在「设置 → AI」用官方 AI 或填自己的模型，从「选题」建一条内容。

可以提升

选题判断、内容结构化，把 AI 稿子改成自己的语气

学习价值

8/10

推荐理由

把采集、选题、写作、剪辑串成一条流水线，省掉工具切换；限制是高级功能要官方额度或自备 Key，剪辑吃内存。

05 / AI生活实验室AI + LIFE

AfterFrame：几万张照片，用一句话搜出来

YIWANG3/AfterFrame ↗
一句话介绍

本地相册工作台，AI 自动给照片写标题和标签，之后按内容搜索、筛选、简单修图。

普通人使用场景

手机相册里几万张照片，想找去年海边那张、或给旅行照批量加文字，只能一页页翻。

小白体验步骤

Releases 下 -setup.exe（Win10/11 64 位），新建目录导入照片，在「设置 → AI 标注」填 Anthropic / OpenAI Key，再整批自动打标签。

可以提升

照片资产管理，用标签搭自己的检索体系

学习价值

8/10

推荐理由

把「找照片」变成「搜照片」，标签还能手改；限制是 AI 标注要自备 Key，贴纸、人像等功能目前只有 macOS 有。
